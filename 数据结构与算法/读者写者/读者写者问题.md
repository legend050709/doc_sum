## 变形一：只允许一人过桥问题
### 问题
有一个东西方向的独木桥，每次只能有一个人通过，且不允许在桥上停留。  
### 分析
相当于读者-写者问题中，==不能读读，不能读写，不能写写==。  
### 实现
```c
Semaphore mutex=1;//互斥信号量，保护临界资源。
main(){
 toWest();
 toEast();
}

toWest(){
 while(1){
  p(mutex);
  从东向西走；
  v(mutex);
 }
}

toEast(){
 while(1){
  p(mutex);
  从西向东走；
  v(mutex);
 }
}
```

## 变形二：多临界区问题

### 问题
一个最多只能容纳两个人的独木桥，东侧和西侧桥段只能容纳一个人，桥中央允许两个人通过。

### 分析
相当于 读者-写者问题中，==临界资源有最大限制，同时将临界资源分为两个小的临界资源==。
有三个临界区，2个临界区只能容纳一个元素，一个临界区可以容纳2个元素。

load =2；互斥信号量，表示桥最多可以容纳两人；
east=1；互斥信号量，表示东端每次最多一个人；
west=1，互斥信号量，表示西侧每次最多走一个人。
//至于桥中间，应为最多可以容纳两人，并且桥的最多容纳也是两人，所以可以省略。

### 实现
```c
Semaphore load=2;//桥可以承载2个人
Semaphore east=1;//东端每次最多一个人
Semaphore west=1;//西段每次最多一个人

main(){
 toEast();toWest();
}

toEast(){
 p(load);
 p(east);
 过东段；
 v(east);

 p(west);
 过西段；
 v(west);
 v(load);
}

toWest(){
 p(load);

 p(west);
 过西段；
 v(west);

 p(east);
 过东段；
 v(east);

 v(load);
}
```

## 变形三：单行道过桥问题
### 问题
有一个单行道的桥，每次可以运行同方向的多个车通过，没有车时，可以任何方向的车通过，当有车在桥上时，同方向的车，可以继续通过，而反方向的车则不允许通过。

### 分析
相当于读者-写者中的，==允许读读，允许写写，不允许读写==。

### 实现
```c
int toeast=0;//往东方向的车数量
int towest=0;//放西方向的车数量
Semaphore toeast_mutex=1;//保护toeast的修改
Semaphore towest_mutex=1;//保护towest的修改
Semaphore mutex=1;//临界资源，防止不同方向的车同时通过。

/*
相当于；
int readerCount=0;
int writerCount=0;//writer的数量
Semaphore rmutex=1;//保护readerCount的修改
Semaphore wmutex=1;//保护writerCount的修改
Semaphore mutex=1;//防止读-写同时
*/

main(){
 toEast();toWest();
}
```
