# nslookup
## 介绍
nslookup属于`bind-utils`包下一个命令
nslookup有两种工作模式：“交互模式”和“非交互模式”。
在命令行中直接输入nslookup，无需输入任何参数即进入交互模式，由“>”提示。

## 使用
```bash
nslookup [参数] [域名]
```
