#  AI系统相关的网络技术

|模块|内容|应用|
|---|---|---|
|**高性能互联技术**|InfiniBand、RoCEv2、RDMA、NVLink、PCIe、NUMA|GPU节点间梯度同步、AllReduce 通信|
|**分布式训练通信框架**|NCCL、Gloo、MPI、Horovod|模型训练时的多GPU/多机通信|
|**存储访问与数据流**|分布式存储（Ceph、NFS、S3）、数据预取、缓存层设计|训练数据高效加载|
|**服务编排与部署**|Kubernetes、Docker、K8s CNI网络、Service Mesh（Istio）|模型推理服务的网络调度与负载均衡|
|**模型推理优化**|Triton Inference Server、gRPC、HTTP/REST API、ZeroMQ|多模型并发推理、低延迟通信设计|

## 底层网络基础

|领域|关键内容|学习建议|
|---|---|---|
|**网络基础**|TCP/IP、UDP、Socket编程、DNS、HTTP/HTTPS、NAT|推荐《TCP/IP详解》《UNIX网络编程》|
|**传输优化**|拥塞控制、零拷贝(sendfile, mmap, RDMA基础)、多路复用(epoll, io_uring)|对理解高性能推理/数据流非常关键|
|**数据中心网络**|L2/L3交换、VLAN/VXLAN、BGP/ECMP、bonding、网络虚拟化|AI 集群部署、NCCL 通信优化都离不开|
|**网络安全**|TLS、证书体系、ACL、防火墙、零信任基础|保护训练数据与模型的通信安全|

## 应用与工程场景

|场景|网络知识的作用|
|---|---|
|**AI训练集群**|优化 GPU 节点间带宽、RDMA 通信调优、NCCL 参数优化|
|**大模型分布式训练**|跨节点参数同步、梯度压缩、AllReduce 优化|
|**推理服务部署**|gRPC + HTTP + 负载均衡（如 Envoy）设计高并发推理|
|**边缘AI / IoT推理**|异地节点通信、带宽受限下模型推理优化|
|**云上AI平台**|K8s 网络编排、服务暴露、安全控制|

# 学习路径（从网络到AI）

- **掌握网络基础**
    - TCP/IP、Socket、epoll、网络性能优化。
        
- **理解高性能通信**
    
    - RDMA、RoCE、NCCL 通信模式。
        
- **熟悉分布式系统**
    
    - 参数服务器（PS）结构、AllReduce算法。
        
- **实践AI训练/推理环境**
    
    - 用 PyTorch/NCCL 搭建多GPU训练；部署 Triton 推理服务。
        
- **理解AI系统架构**
    
    - 学习“从模型训练到部署”的端到端系统。

## 分阶段学习

### 阶段一：基础打牢（1–2 个月）
**目标**：掌握网络编程和性能优化的底层能力，为 AI 系统通信打下基础。

|模块|关键知识点|实践建议|推荐资料|
|---|---|---|---|
|网络基础|TCP/IP 协议栈、三次握手、拥塞控制、UDP|用 `nc`、`tcpdump`、`wireshark` 观察数据包流|《TCP/IP详解 卷1》|
|Socket 编程|TCP/UDP Socket、epoll、io_uring、非阻塞I/O|用C语言写一个 echo server + 客户端|《UNIX网络编程 卷1》|
|性能优化|零拷贝(sendfile/mmap)、多线程网络服务、NUMA 亲和性|测试带宽与延迟性能差异|man pages + 内核文档|
|Linux 调优|网络缓冲区、RSS/RPS、bonding、ethtool|调优某服务器的网络栈参数|Brendan Gregg 博客|


### 阶段二：高性能通信与分布式系统（2–3 个月）
**目标**：理解 AI 训练中节点通信机制与底层实现。

|模块|关键知识点|实践建议|推荐资料|
|---|---|---|---|
|高性能互联|RDMA、RoCEv2、InfiniBand、QP、CQ、MR|使用 RDMA core 编写基础 send/recv 程序|Mellanox RDMA 编程指南|
|分布式通信|NCCL、MPI、Gloo、Horovod、AllReduce算法|PyTorch 多GPU分布式训练实验|PyTorch Distributed 文档|
|NUMA 与多GPU|NUMA 绑定、GPU affinity、PCIe 拓扑|用 `numactl`, `nvidia-smi topo` 优化|Linux NUMA 文档|
|数据流与存储|Ceph、NFS、S3、cache prefetch|设计一个数据加载管线|Ceph 官方手册|


### 阶段三：AI 系统与推理架构（2–3 个月）
**目标**：掌握 AI 训练与推理平台的网络架构与部署。

|模块|关键知识点|实践建议|推荐资料|
|---|---|---|---|
|AI 训练框架|PyTorch、TensorFlow、DeepSpeed|运行多GPU分布式训练|官方教程|
|推理引擎|NVIDIA Triton、ONNX Runtime、TensorRT|部署模型推理服务|NVIDIA Triton Docs|
|服务接口|gRPC、REST、ZeroMQ、消息队列|写一个 gRPC 推理服务|gRPC 官方教程|
|云原生部署|Docker、Kubernetes、K8s CNI、Service Mesh|部署 Triton 推理服务到 K8s|Kubernetes 官网|
|性能监控|Prometheus、Grafana、网络带宽监控|观察 NCCL 通信性能|NVIDIA Nsight / DCGM|

### 阶段四：系统整合与项目实战（持续）

**目标**：整合前面知识，构建端到端 AI 系统。

|项目|内容|说明|
|---|---|---|
|**项目1：AI 推理加速平台**|Triton + gRPC + 负载均衡 + Prometheus|实现高并发模型推理系统|
|**项目2：分布式训练集群**|多机多GPU + NCCL + RDMA 优化|复现 AllReduce 性能优化|
|**项目3：智能监控系统**|GPU/网络/CPU 利用率分析 + 可视化|用 Grafana 展示 AI 集群性能|
|**项目4（选）**：边缘AI系统|低带宽推理、模型压缩、远程调度|结合网络优化与 AI 轻量化|
