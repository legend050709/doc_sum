# MPI的作用
## 分布式并行计算
```bash
┌──────────┐     ┌──────────┐     ┌──────────┐
│ Process 0│────▶│ Process 1│────▶│ Process 2│
│  Node 1  │     │  Node 2  │     │  Node 3  │
└──────────┘     └──────────┘     └──────────┘
     │                │                │
     └────────────────┴────────────────┘
                   MPI 通信
```

(1)解决的问题

- **数据并行**：将大数据分割到多个进程处理
- **任务并行**：不同进程执行不同任务
- **跨节点通信**：进程可以在不同物理机器上

(2)典型应用
- 科学计算（气候模拟、分子动力学）
- 机器学习（分布式训练）
- 大数据分析（Spark MPI 模式）
- 高性能计算



# MPI和RDMA的配合

应用程序调用MPI API接口，RDMA 作为 MPI API接口的传输层。

```bash
┌─────────────────────────────────────────────┐
│            应用层（用户代码）                │
├─────────────────────────────────────────────┤
│              MPI API 层                      │
│   MPI_Send, MPI_Recv, MPI_Bcast, ...        │
├─────────────────────────────────────────────┤
│            MPI 传输层（BTL）                 │
│   支持 TCP, 共享内存, RDMA 等               │
├─────────────────────────────────────────────┤
│            RDMA / libibverbs                │
│   ibv_post_send, ibv_post_recv, ...         │
├─────────────────────────────────────────────┤
│            硬件层                            │
│   InfiniBand HCA / RoCE NIC                 │
└─────────────────────────────────────────────┘
```
