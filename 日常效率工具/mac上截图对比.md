# mac上截图
## 方式一：`Shift+Command+4`
- **功能**： 截取自定义区域的屏幕截图（光标会变成十字坐标）。
- **存储位置**： 直接保存为 PNG 图片文件到桌面（默认命名为`屏幕截图日期时间.png`）。

## 方式二：`Shift+Command+Ctrl+4`

- **功能**： 截取自定义区域的屏幕截图，但不保存为文件。
- **存储位置**： 截图直接存入剪贴板（Clipboard），不会生成文件。
-**使用**：`cmd + 空格`搜索`便笺（Sticky Notes）`，然后`cmd+v`，将剪贴板中的截图粘贴保存到便签中。


# 截图对比
## 需求
使用`mac`来查看文档时，如果文档中有2个表格，分别代表2个厂家的网卡的性能数据，2个表格在文档中距离挺远的，想要对比着2个表格，不太好看。
如何截图其中一个表格，快速显示到另外一个表格附近，进行对比。

## 方法一：`Shift+Command+4` 保存图片 + 滚动文档
使用 `Shift+Command+4` 选择截图区域，进行截图。图片会保存到桌面。然后点击桌面上的图片，同时滚动文档到指定的位置，进行2个对比。

## 方法一：`Shift+Command+Ctrl+4` 保存到便签中 + 滚动文档
使用 `Shift+Command+Ctrl+4` 选择截图区域，进行截图，截图会保存到剪贴板。
`cmd + 空格`搜索`便笺（Sticky Notes）`，然后`cmd+v`，将剪贴板中的截图粘贴保存到便签中。
然后点击桌面上的图片，同时滚动文档到指定的位置，进行2个对比。
