# 打包

所谓打包，就是将一个文件、或者一堆文件打包成一个单一文件的过程。

# 压缩
## 常用命令简介
`zip`，对应压缩文件格式：.`zip`  
`gzip`，对应压缩文件格式：`.gz`  
`bzip2`，对应压缩文件格式：.`bz2`  
`xz`，对应压缩文件格式：.`xz`

打包命令是 tar.
如果和 `gzip` 一块使用：`.tar.gz` 或者 `.tgz`  
如果和 `bzip2` 一块使用：`.tar.bz2`  
如果和 `xz` 一块使用：`.tar.xz`

## 压缩率

压缩率。其计算公式是：（压缩后文件体积） / （压缩前文件体积）。

## 打包和压缩的结合

还有一点是：gzip bzip2 xz 这几个命令都只能对但一个文件做压缩，不能压缩一个目录，压缩目录需要通过 tar 配合这几个压缩命令来处理，或者使用 zip 命令

### 使用

#### 压缩

默认情况下，xz 命令也是就地压缩，原始文件将被覆盖。
压缩完后，会在当前目录下生成 <file_name>.xz 文件。
压缩完成之后，可以使用 -l 参数，来查看压缩前后的文件对比信息。

```bash

xz <file_name> // 压缩文件
xz -v <file_name>   // 加上 -v 参数查看压缩率：

xz -l <file_name>.xz // 查看压缩前后的文件对比信息：
```

#### 解压缩

```bash
xz -d <file_name>.xz
```
