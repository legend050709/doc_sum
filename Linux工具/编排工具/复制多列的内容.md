# 背景

在 item 的 输出中，或者 sublime 中 如果期望

# 解决

```
使用方法：
	cmd + alt/option + 按住鼠标左边选择范围

注：选择完范围，对于item而言默认就已经复制了；
   对于sublime 而言，可能还需要再次 cmd+c 进行复制。
```
