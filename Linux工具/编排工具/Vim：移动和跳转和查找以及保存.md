# 前言
我们知道，vim中的 `hjkl` 可以上下左右进行移动光标。
假设你使用的是 MacBook，打开 `系统偏好设置 > 键盘`，把「按键重复」和「重复前延迟」都调整到最快。

「按键重复」决定了当你长按某一个按键的时候系统会以多快的速度重复输入这个按键，「重复前延迟」决定了当你开始长按多久过后系统会开始重复输入。把这两个选项都调到最快，可以让光标的移动更快。

# 实际行的移动
## 上下移动
```bash
gg: 移动到文件的第一行
G:  移动到文件的最后一行

j:   向下移动 1行；
k:   向上移动 1行;
Nj:  向下移动 N行；
Nk:  向上移动 N行;
```
## 左右移动
### 移动到行首和行尾
移动到行首（文件行/实际行）和行尾的 `0` 和 `$` 命令；
### 基于单词的移动

|命令|移动位置|
|---|---|
|`w`|到当前单词的下一个单词的开头 - for**w**ard / **w**ord|
|`b`|到当前单词 或者 上一个单词的开头 - **b**ackward|
|`e`|到当前单词 或者 下一个单词的结尾|
|`ge`|到上一个单词的结尾|

> `ea` 连在一起可以实现「移动到当前单词结尾并在后面插入」，记住它，使用频率很高。


# 屏幕行的移动
## 什么是屏幕行

如果你使用的是现代 ide 的 Vim 模式，那么在屏幕左侧应该已经有行号标识了。如果你是在终端当中使用 Vim，你可能需要 `:set number` 命令打开行号显示。
![](attachments/Pasted%20image%2020240328164827.png)

如图所示，光标现在在第 3 行开头 **N**isi 位置，此时我们按下 `j`，光标移动到了第四行(此中的4行是文件行或者实际行，不是屏幕行)，而不是 `Nisi` 下面的 `qui`。
这是**因为  `jk` 是按照实际行，也就是文本在文档中真实的行，进行移动的 。**

而当一行文本的长度超过的窗口的宽度，Vim 会把这一行折行显示，文件中的一行可能会显示成屏幕上的若干行。

## 屏幕行移动
### 上下移动
在 Vim 中想要按屏幕行上下移动（本例中从 **N**isi  移动到 `qui`），可以用 `gj` 和 `gk` 命令。
```bash
gj: 向下移动一个屏幕行；
Ngj：向下移动 n 个屏幕行；比如：3gj:

gk:  向上移动一个屏幕行；
Ngk:  向上移动n个屏幕行；比如： 3gk:
```

### 左右移动
移动到行首（文件行/实际行）和行尾的 `0` 和 `$` 命令；
同样也有屏幕行和实际行之分，按屏幕行的首尾移动，可以使用 `g0`、`g$`。


# 字符串查找
## 不区分大小写查找
`/String\c` : 表示 string 不区分大小写的进行查找。
## 查找多个字段
你可以使用正则表达式来搜索多个字段。使用 `\|` 来表示“或”条件。
即：`/aa|bb` 但是由于`|`需要转义，因此为 `/aa\|bb`

**示例**：  
如果你想搜索“apple”或“orange”，可以在 `vim` 中输入：
```bash
/apples\|oranges
```


## 移动
在 Vim 中可以用 `/String` 来进行字符串、跨行的查找。
与之匹配的前一个/后一个的命令是 `N/n`（**n**ext），大写向前，小写向后。



# 标记移动
## 背景
有的时候，我们可能要在两个位置间来回跳转。这个时候，最方便的办法就是使用「标记（mark）」。

## 使用
`m{a-zA-Z}` 会用紧跟着输入的字母标记当前光标所在位置，例如 `ma` 把当前位置标记为 `a`。标记好之后，当我们移动到另外一个地方的时候，只要**两个键**就能跳转回来。
跳转回来有两种方式，以刚刚提到的标记 `a` 为例：
`'a（注意a前也有一个字符）` 会跳转到标记的所在行的第一个非空白字符；
`` `a（注意a前也有一个字符） `` 不仅会跳转到标记所在行，还会定位到标记所在的确切位置；

大多数时候，只要反复使用 `mm` 和 `` `m `` 就可以方便地来回跳转了。

# 括号内的跳转和操作
## 背景
代码中经常有圆括号`(`、尖括号`<`、方括号`[`、引号`"`、大括号`{`、html 标签、整个单词（word）等内容，Vim 也有一系列命令可以对和括号等内容相关的文本进行操作，在 Vim 中，我们把这些命令操作的内容称作「文本对象」。

## 操作
文本对象由两个字符组成，第一个字符永远是 `i` 或 `a`。
可以把 `i` 想象成 **i**nner 或者 **i**nside，
而把 `a` 想象成 **a**round。

### 选中
v: 表示选中。
```bash
v + a/i + 对象： 表示选中。
比如：
	vi]、va] 等
```
![](attachments/Pasted%20image%2020240328171847.png)
```补充：
va{ 或者 va}:  选中{}及其内部的内容。
va( 或者 va):  选中()及其内部的内容。
```

![](attachments/Pasted%20image%2020240328171924.png)

其实，单词(word)也可以看成一个文本对象。对齐的操作也是类似：
```bash
viw: 选中单词
diw: 删除选中的单词
viw + y: 复制整个单词;
viw + c 或者 ciw : 更改整个单词；


其他：
vw:
dw:
vaw: 
daw: 
```

### 其他操作
同样，文本对象也可以搭配 `d` delete、`c` change、`y` yank 命令进行操作，例如：`da"` - 删除一对双引号及之间的内容（delete **a**round "），`cit` - 修改一对 html 标签之内的内容。

`i`、`a` 还可以搭配上面提到的 `w` 使用，例如：`diw` 删除当前单词，`dw` 删除当前单词及后面的空格，搭配 `c`、`v`、`y` 也类似。

## 跳转
`%` 命令让我们可以在匹配的括号间**来回跳转**。
这个命令**无需我们手动指明要跳转的括号**，而是自动根据当前光标所在位置的上一层括号来进行跳转。

# 文件保存
## 指定范围的行保存到新文件
### 覆盖方式
```bash
:10,20w output.txt
```
### 追加方式
```bash
:10,20w >> output.txt
```
