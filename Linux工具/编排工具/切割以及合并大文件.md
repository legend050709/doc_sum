# 背景
当机器上存在很大的文件时，通过vim 查看会占用很大量的内层，此中方法不可取。通过less查看，想要做到全局搜索又比较慢。
能否将一个大文件，切割成小文件， 在小文件中查找需要的信息。用到了分治法。
split命令用于将一个大文件切割为多个小文件，并且保存原始大文件不变。

# 介绍
文件分割可以使用split命令，既支持文本文件分割，又支持二进制文件分割。
而合并文件可以使用cat命令。
分割文本文件时，可以按文件大小分割，也可以按文本行数分割。

```c

```
