# LazyVim 
## 介绍
LazyVim 是由 lazy.nvim 提供支持的 Neovim 配置，即：LazyVim是  Neovim 的配置，可以轻松自定义和扩展相关的配置，通过LazyVim就不需要再在从头开始进行配置，它预先已经配置了大量的插件，可以做到开箱即用的效果，能够瞬间让Neovim拥有其他IDE的目录、补全、跳转等功能。

这里需要再重复解释一下，LazyVim并不是Neovim的替代品，它只是按照「约定大于习惯」的原则把一些常用、好用的插件、配置预置到了配置文件里。

所以，要想使用LazyVim，首先需要按照Neovim，然后再安装LazyVim，当打开Neovim时，它会自动加载配置和插件，迅速完成Neovim的配置。
