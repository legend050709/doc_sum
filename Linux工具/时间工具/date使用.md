# 应用
## 查看毫秒级别的时间
```c
# date +%Y-%m-%d %H:%M:%S:%N
2021-06-30 15:50:16:123456789

或者 
# date +%T.%N
19:39:18.875596287
```

## 计算时间差值

如下所示，计算时间的差值， 精确到ms。
```bash
# 获取当前时间戳（毫秒）
start=$(date +%s%3N)

# 这里执行你的操作...
sleep 1

# 获取结束时间戳（毫秒）
end=$(date +%s%3N)

# 计算差值
diff=$(( end - start ))

echo "Execution time: $diff milliseconds"
```

说明：
```bash
这里的关键是date +%s%3N，它会返回当前时间的时间戳。
其中%s代表秒数，从1970年1月1日00:00:00 UTC开始的秒数，
%3N代表毫秒，三位数字表示。
```


## 时间戳和时间互转
### 时间戳转换为时间
时间戳是指从 1970 年 1 月 1 日 00:00:00 UTC（即 Unix 时间戳的起点）到某一时间的秒数。
```
date -d @时间戳

date -d @时间戳 +"%Y-%m-%d %H:%M:%S"
```

范例：
```bash
# date -d @1614592163 +"%Y-%m-%d %H:%M:%S"
2021-03-01 17:49:23

# date -d @1711020759
Thu Mar 21 19:32:39 CST 2024

# date -d @1711020770
Thu Mar 21 19:32:50 CST 2024
```

### 时间转换为时间戳

显示指定时间的时间戳：
```bash
# date -d '2021-03-01 17:49:23' +%s
1614592163
```

 用时间戳显示当前时间：
```bash
# date +%s

# date +%s
1614591960
```
