## 场景二：某个进程被其他进程抢占CPU但不知道具体哪个
### renice 设置进程的优先级
#### 介绍
在 Linux 系统中，`nice` 和 `renice` 命令可以用来调整进程的优先级。`nice` 通常用于启动新进程时设置初始优先级，而 `renice` 则用于调整已经运行的进程的优先级。

#### 使用
```bash
renice [优先级] -p [进程ID]
```
 `[优先级]`：要设置的新优先级值，范围从 -20（最高优先级）到 19（最低优先级）。
 `[进程ID]`：要调整优先级的进程的 PID。


**(1)调整进程下单个线程的优先级**:

如果您想单独调整某个线程的优先级，您需要找到该线程的线程 ID (TID)。
```bash
可以使用 `ps` 命令来列出该进程的所有线程：
ps -T -p 1234

使用 `renice` 命令调整特定线程的优先级：
renice -10 -p [线程ID]
```


**(2)调整进程下所有线程的优先级**
```
renice -10 -p 1234
```
这条命令将把进程 1234 的优先级设置为 `-10`，并不会将整个进程的所有线程的优先级设置为 10.

如果将所有的线程的优先级都设置一遍， 则通过下面的方法。
```bash
all_tid=($(ps -T -p `pidof named` | grep -v PID | awk '{print $2}')); for a in "${all_tid[@]}"; do renice -10 -p ${a}; done
```

**（3）查看整个进程下的线程的优先级**
```bash
top -p PID -H
```
