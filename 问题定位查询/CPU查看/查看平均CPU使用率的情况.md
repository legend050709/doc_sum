# 背景
`ps` 以及 `top`命令 都是查看的是实时的CPU负载情况。
如果存在流量的微突发（比如100ms内有突发，后续平稳），或者定时任务（任务执行完退出）、CPU抢占（一个进程抢占其他进程的CPU，造成其他进程的延迟大，以及丢包等），像以上的情况，都是发生在很短的时间内。那么一段时间之后，通过 `ps`或者`top`是无法观察到上面的现象的。

## 更细粒度的实时CPU查看
虽然 `top` 和 `htop` 默认是以秒为单位刷新，但你可以通过设置更短的刷新间隔来获得更频繁的更新。例如，在 `top` 中，你可以按下 `d` 键并输入更小的值（如 0.1），以每 0.1 秒更新一次。
