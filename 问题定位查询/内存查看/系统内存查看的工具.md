## numastat 应用场景
### 查看各 numa 节点的内存使用情况
**背景**：
比如，明明通过`free` 查看系统内存还存在很多，但是 `swap` 去很高，则是有可能某一个`NUMA` 节点的内存被使用了很多。因此，需要查看每个NUMA节点的内存情况。

**查看**：
```bash
numastat -m -v

or

cat /proc/buddyinfo

or 

numactl --hardware
```
![](attachments/Pasted%20image%2020240315152536.png)

![](attachments/Pasted%20image%2020240315155022.png)
### 查看某个进程在各个NUMA上的真实内存的占用
```bash
numastat -p PID
```
注意：此中查看的是真实内存的情况。

### 查看线程跨numa访问内存的情况
```bash
numastat -n

- `numa_hit` 表示节点内 CPU 核访问本地内存的次数。
- `numa_miss` 表示节点内核访问其他节点内存的次数。跨节点的内存访问会存在高延迟从而降低性能，因此 `numa_miss` 的值应当越低越好，如果过高，则应当考虑绑核。
```
