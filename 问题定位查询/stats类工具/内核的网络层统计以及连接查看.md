# 前言

如果查看网络层的链接情况：可以通过 `netstat` 命令，`ss`命令、`/proc/net/udp`、 `/proc/net/tcp` 来查看具体的链接情况。

如果查看网络层的统计情况，则可以通过 `netstat -s`、`ss -s`，`/proc/net/snmp`、`/proc/net/netstat` 来查看具体的内核网络层的统计情况。

注：**更加建议通过  /proc/net/snmp、/proc/net/netstat 文件的方式来查看统计计数**，而不是 `ss -s` 或者 `netstat -s` 的方式。因为 `netstat -s`  可能输出字段不全，另外，输出字段的字符串可能随着内核版本存在变化。

## /proc/net/netstat文件

### 可读显示脚本
在查看centos机器的网络状态时，尝尝要看看计数器文件/proc/net/netstat，但是直接cat，如下显示. 很难读取。
![](attachments/Pasted%20image%2020231113200806.png)
上面这个太难看懂，有如下awk脚本，可以格式化：
```c
cat /proc/net/netstat |  awk '(f==0) {name=$1; i=2; while ( i<=NF) {n[i] = $i; i++ }; f=1; next} (f==1){ i=2; while ( i<=NF){ printf "%s%s = %d\n", name, n[i], $i; i++}; f=0} '

注：格式化显示的依然是原本的累计值。
或者
【以下是不去除0值】
awk '{if (NR % 2 == 0) print $1;for(i = 2; i <= NF; i++) {if (NR % 2 ) count[i]=$i; else printf("    %-28s%d\n",count[i], $i);}}' /proc/net/netstat

或者 
【以下是去除0值】
awk '{if (NR % 2 == 0) print $1;for(i = 2; i <= NF; i++) {if (NR % 2 ) count[i]=$i; else if ($i > 0 ) printf("    %-28s%d\n",count[i], $i);}}' /proc/net/netstat
```

### 查看数值变化
结合`watch`命令就能定时得查看这些值的变化，命令如下：
```bash
watch -n 1 "awk '{if (NR % 2 == 0) print \$1;for(i = 2; i <= NF; i++) {if (NR % 2 ) count[i]=\$i; else if (\$i > 0 ) printf(\"    %-28s%d\n\",count[i], \$i);}}' /proc/net/netstat"
```

更进一步，`watch` 命令只能看到某个时间点的数值统计，如果想查看每秒钟数值的变化，就不那么容易了。如下所示：
```bash
echo '' > tmp.txt; \
for((i = 1; ; i++)); do \
    awk '{for(i = 2; i <= NF; i++) {if (NR % 2 ) count[i] = $i; else if ($i > 0 ) print count[i], $i;}}' \
        /proc/net/snmp /proc/net/netstat >> tmp.txt; \
    if [ `expr $i % 2` == 0 ]; then \
        printf "\033c"; \
        awk '{if (a[$1]) {if ($2 != a[$1]) printf("%-28s%d\n", $1, $2 - a[$1])} else a[$1] = $2;}' tmp.txt; \
        echo '' > tmp.txt;\
    else \
        sleep 1;\
    fi; \
done
```
