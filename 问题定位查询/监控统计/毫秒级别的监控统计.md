# 毫秒级别的监控统计

## 分类
- ip -s link：侧重于接口的统计
- netstat -s：侧重于协议的统计
- ethtool -S：也是接接口统计

## snmp统计UDP
如下所示，每隔`20ms`查看一下，snmp在udp上的收发包的统计。
```bash
# cat test_snmp.sh

out_file=$1
while true;do echo -n $(date +%T.%N) " " >> ${out_file}; read Udp InDatagrams NoPorts InErrors OutDatagrams RcvbufErrors SndbufErrors InCsumErrors o <<<$(grep Udp: /proc/net/snmp |grep -v InDatagrams );echo $((InDatagrams-pInDatagrams)) $((NoPorts-pNoPorts)) $((InErrors-pInErrors)) $((OutDatagrams-pOutDatagrams)) $((RcvbufErrors-pRcvbufErrors)) $((SndbufErrors-pSndbufErrors)) $((InCsumErrors-pInCsumErrors)) >> ${out_file};pInDatagrams=$InDatagrams;pNoPorts=$NoPorts;pInErrors=$InErrors;pOutDatagrams=$OutDatagrams;pRcvbufErrors=$RcvbufErrors;pSndbufErrors=$SndbufErrors;pInCsumErrors=$InCsumErrors;usleep 20000;done
```

### snmp和 `netstat -s`对比
注：直接查看 `/proc/net/snmp`, 比使用  `netstat -s`效率更高。

### snmp和`/proc/net/udp`对比
`/proc/net/udp` 查看的是 `udp socket`的相关信息以及统计。
另外，`snmp`统计`UDP` 的`RcvbufErrors`是所有的`udp socket`的统计，`/proc/net/udp`可以看到每个`udp socket`的丢包统计。

## 网口统计`ethtool -S`
监控这些数据比较困难。因为用命令行获取很容易，但是以上字段并没有一个统一的标准。 不同的驱动，甚至同一驱动的不同版本可能字段都会有差异。



### 和 `cat /sys/class/net/(nic)/statistics` 对比
sysfs 也提供了统计信息，但相比于`ethtool -S`网卡层的统计，要更上层一些。

### 和 `/proc/net/dev`
`/proc/net/dev` 提供了更高一层的网卡统计。
这个文件里显式的统计只是 sysfs 里面的一个子集，但适合作为一个常规的统计参考。

## 综合
将 上面的 网络接口的统计，`snmp`的统计，`cat /sys/class/net/(nic)/statistics` 的统计，`ethtool -S`的统计 给综合一下。

```bash
# cat test_snmp.sh

out_file=$1
while true;do 
    echo -n $(date +%T.%N) " " >> ${out_file}
    read Udp InDatagrams NoPorts InErrors OutDatagrams RcvbufErrors SndbufErrors InCsumErrors o <<<$(grep Udp: /proc/net/snmp |grep -v InDatagrams )

    rx_unicast=$(ethtool -S eth01 | grep "rx_unicast:" | awk '{print $2}')
    rx_dropped=$(ethtool -S eth01 | grep "rx_dropped:" | awk '{print $2}')
    tx_unicast=$(ethtool -S eth01 | grep "tx_unicast:" | awk '{print $2}')
    tx_errors=$(ethtool -S eth01 | grep "tx_errors:" | awk '{print $2}')

    s_rx_packets=$(cat /sys/class/net/eth01/statistics/rx_packets)
    s_rx_dropped=$(cat /sys/class/net/eth01/statistics/rx_dropped)
    s_rx_errors=$(cat /sys/class/net/eth01/statistics/rx_errors)
    s_tx_dropped=$(cat /sys/class/net/eth01/statistics/tx_dropped)
    s_tx_errors=$(cat /sys/class/net/eth01/statistics/tx_errors)
    s_tx_packets=$(cat /sys/class/net/eth01/statistics/tx_packets)

    echo -n $((InDatagrams-pInDatagrams)) $((NoPorts-pNoPorts)) $((InErrors-pInErrors)) $((OutDatagrams-pOutDatagrams)) $((RcvbufErrors-pRcvbufErrors)) $((SndbufErrors-pSndbufErrors)) $((InCsumErrors-pInCsumErrors)) >> ${out_file}

    echo -n "; " $((rx_unicast-prx_unicast)) $((rx_dropped-prx_dropped)) $((tx_unicast-ptx_unicast)) $((tx_errors-ptx_errors)) >> ${out_file}
    
    echo "; " $((s_rx_packets-ps_rx_packets)) $((s_rx_dropped-ps_rx_dropped)) $((s_rx_errors-ps_rx_errors)) $((s_tx_packets-ps_tx_packets)) $((s_tx_dropped-ps_tx_dropped)) $((s_tx_errors-ps_tx_errors)) >> ${out_file}

    pInDatagrams=$InDatagrams
    pNoPorts=$NoPorts
    pInErrors=$InErrors
    pOutDatagrams=$OutDatagrams
    pRcvbufErrors=$RcvbufErrors
    pSndbufErrors=$SndbufErrors
    pInCsumErrors=$InCsumErrors

    prx_unicast=$rx_unicast
    prx_dropped=$rx_dropped
    ptx_unicast=$tx_unicast
    ptx_errors=$tx_errors

    ps_rx_packets=$s_rx_packets
    ps_rx_dropped=$s_rx_dropped
    ps_rx_errors=$s_rx_errors
    ps_tx_dropped=$s_tx_dropped
    ps_tx_errors=$s_tx_errors
    ps_tx_packets=$s_tx_packets   


    usleep 20000
done
done
```
