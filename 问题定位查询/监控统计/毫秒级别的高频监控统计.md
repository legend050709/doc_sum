# 背景
（1）如果流量存在微突发，导致`socket`的缓冲区满出现，或者其他异常。
（2）对于RDMA流量，由于高带宽，低时延的特性，因此需要监控也是高频展示，需要毫秒级别的监控统计。


# 毫秒级别的监控统计

## 分类
```bash
(1) ip -s link：侧重于接口的统计
(2) netstat -s：侧重于协议的统计
(3) ethtool -S：也是接接口统计
(4) /sys/class 文件系统
```

## snmp统计UDP
如下所示，每隔`20ms`查看一下，snmp在udp上的收发包的统计。
```bash
# cat test_snmp.sh

out_file=$1
while true;do echo -n $(date +%T.%N) " " >> ${out_file}; read Udp InDatagrams NoPorts InErrors OutDatagrams RcvbufErrors SndbufErrors InCsumErrors o <<<$(grep Udp: /proc/net/snmp |grep -v InDatagrams );echo $((InDatagrams-pInDatagrams)) $((NoPorts-pNoPorts)) $((InErrors-pInErrors)) $((OutDatagrams-pOutDatagrams)) $((RcvbufErrors-pRcvbufErrors)) $((SndbufErrors-pSndbufErrors)) $((InCsumErrors-pInCsumErrors)) >> ${out_file};pInDatagrams=$InDatagrams;pNoPorts=$NoPorts;pInErrors=$InErrors;pOutDatagrams=$OutDatagrams;pRcvbufErrors=$RcvbufErrors;pSndbufErrors=$SndbufErrors;pInCsumErrors=$InCsumErrors;usleep 20000;done
```

### snmp和 `netstat -s`对比
注：直接查看 `/proc/net/snmp`, 比使用  `netstat -s`效率更高。

### snmp和`/proc/net/udp`对比
`/proc/net/udp` 查看的是 `udp socket`的相关信息以及统计。
另外，`snmp`统计`UDP` 的`RcvbufErrors`是所有的`udp socket`的统计，`/proc/net/udp`可以看到每个`udp socket`的丢包统计。

## 网口统计`ethtool -S`
监控这些数据比较困难。因为用命令行获取很容易，但是以上字段并没有一个统一的标准。 不同的驱动，甚至同一驱动的不同版本可能字段都会有差异。



### 和 `cat /sys/class/net/(nic)/statistics` 对比
sysfs 也提供了统计信息，但相比于`ethtool -S`网卡层的统计，要更上层一些。

### 和 `/proc/net/dev`
`/proc/net/dev` 提供了更高一层的网卡统计。
这个文件里显式的统计只是 sysfs 里面的一个子集，但适合作为一个常规的统计参考。

## 综合
将 上面的 网络接口的统计，`snmp`的统计，`cat /sys/class/net/(nic)/statistics` 的统计，`ethtool -S`的统计 给综合一下。

```bash
# cat test_snmp.sh

out_file=$1
while true;do 
    echo -n $(date +%T.%N) " " >> ${out_file}
    read Udp InDatagrams NoPorts InErrors OutDatagrams RcvbufErrors SndbufErrors InCsumErrors o <<<$(grep Udp: /proc/net/snmp |grep -v InDatagrams )

    rx_unicast=$(ethtool -S eth01 | grep "rx_unicast:" | awk '{print $2}')
    rx_dropped=$(ethtool -S eth01 | grep "rx_dropped:" | awk '{print $2}')
    tx_unicast=$(ethtool -S eth01 | grep "tx_unicast:" | awk '{print $2}')
    tx_errors=$(ethtool -S eth01 | grep "tx_errors:" | awk '{print $2}')

    s_rx_packets=$(cat /sys/class/net/eth01/statistics/rx_packets)
    s_rx_dropped=$(cat /sys/class/net/eth01/statistics/rx_dropped)
    s_rx_errors=$(cat /sys/class/net/eth01/statistics/rx_errors)
    s_tx_dropped=$(cat /sys/class/net/eth01/statistics/tx_dropped)
    s_tx_errors=$(cat /sys/class/net/eth01/statistics/tx_errors)
    s_tx_packets=$(cat /sys/class/net/eth01/statistics/tx_packets)

    echo -n $((InDatagrams-pInDatagrams)) $((NoPorts-pNoPorts)) $((InErrors-pInErrors)) $((OutDatagrams-pOutDatagrams)) $((RcvbufErrors-pRcvbufErrors)) $((SndbufErrors-pSndbufErrors)) $((InCsumErrors-pInCsumErrors)) >> ${out_file}

    echo -n "; " $((rx_unicast-prx_unicast)) $((rx_dropped-prx_dropped)) $((tx_unicast-ptx_unicast)) $((tx_errors-ptx_errors)) >> ${out_file}
    
    echo "; " $((s_rx_packets-ps_rx_packets)) $((s_rx_dropped-ps_rx_dropped)) $((s_rx_errors-ps_rx_errors)) $((s_tx_packets-ps_tx_packets)) $((s_tx_dropped-ps_tx_dropped)) $((s_tx_errors-ps_tx_errors)) >> ${out_file}

    pInDatagrams=$InDatagrams
    pNoPorts=$NoPorts
    pInErrors=$InErrors
    pOutDatagrams=$OutDatagrams
    pRcvbufErrors=$RcvbufErrors
    pSndbufErrors=$SndbufErrors
    pInCsumErrors=$InCsumErrors

    prx_unicast=$rx_unicast
    prx_dropped=$rx_dropped
    ptx_unicast=$tx_unicast
    ptx_errors=$tx_errors

    ps_rx_packets=$s_rx_packets
    ps_rx_dropped=$s_rx_dropped
    ps_rx_errors=$s_rx_errors
    ps_tx_dropped=$s_tx_dropped
    ps_tx_errors=$s_tx_errors
    ps_tx_packets=$s_tx_packets   


    usleep 20000
done
done
```

# 毫秒级别的监控的难点
```bash
(1) ip -s link：侧重于接口的统计
(2) netstat -s：侧重于协议的统计
(3) ethtool -S：也是接接口统计
(4) /sys/class 文件系统
```

上面的查看监控统计，使用`shell bash` 命令的方式，难以作为**毫秒级别的高频监控统计**。
使用`bash`命令的话，每个命令都涉及到进程的创建，销毁，同时还可能涉及到文本的解析，匹配，过滤等操作。

## 思路
可以考虑使用`C`语言实现监控的读取，比如：`ethtool -S`输出的读取，`/sys/class` 文件系统的读取等等。

## `ethtool -S`输出的C语言实现
```bash
- `ethtool` 在内核中通过 ioctl（`SIOCETHTOOL`）接口与网卡驱动通信；
- 获取统计数据（`ETHTOOL_GSTATS`）通常只涉及内核内存的复制，速度非常快（微秒级）；
- 在高性能网络监控、RDMA 性能测试、DPDK 旁路监控等场景中非常常见；
- 可用于获取如：`rx_packets`, `tx_packets`, `rx_errors`, `tx_errors`, `rx_bytes` 等硬件计数器。
```


范例如下所示：
```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <unistd.h>
#include <sys/ioctl.h>
#include <linux/ethtool.h>
#include <linux/sockios.h>
#include <net/if.h>
#include <stdint.h>
#include <errno.h>

#define MAX_STATS 2048

int main(int argc, char *argv[]) {
    const char *ifname = argc > 1 ? argv[1] : "eth0";
    int sock = socket(AF_INET, SOCK_DGRAM, 0);
    if (sock < 0) {
        perror("socket");
        return 1;
    }

    struct ifreq ifr;
    memset(&ifr, 0, sizeof(ifr));
    strncpy(ifr.ifr_name, ifname, IFNAMSIZ - 1);

    // Step 1: 获取统计个数
    size_t sset_info_size = sizeof(struct ethtool_sset_info) + sizeof(__u32) * 1;
    struct ethtool_sset_info *sset_info = calloc(1, sset_info_size);
    if (!sset_info) {
        perror("calloc");
        close(sock);
        return 1;
    }

    sset_info->cmd = ETHTOOL_GSSET_INFO;
    sset_info->sset_mask = 1ULL << ETH_SS_STATS;
    ifr.ifr_data = (void *)sset_info;

    if (ioctl(sock, SIOCETHTOOL, &ifr) < 0) {
        perror("ETHTOOL_GSSET_INFO");
        free(sset_info);
        close(sock);
        return 1;
    }

    int n_stats = sset_info->data[0];
    free(sset_info);

    if (n_stats <= 0 || n_stats > MAX_STATS) {
        fprintf(stderr, "Invalid number of stats: %d\n", n_stats);
        close(sock);
        return 1;
    }

    // Step 2: 获取统计字段名
    size_t names_len = sizeof(struct ethtool_gstrings) + n_stats * ETH_GSTRING_LEN;
    struct ethtool_gstrings *gstrings = malloc(names_len);
    if (!gstrings) {
        perror("malloc gstrings");
        close(sock);
        return 1;
    }
    memset(gstrings, 0, names_len);
    gstrings->cmd = ETHTOOL_GSTRINGS;
    gstrings->string_set = ETH_SS_STATS;
    ifr.ifr_data = (void *)gstrings;

    if (ioctl(sock, SIOCETHTOOL, &ifr) < 0) {
        perror("ETHTOOL_GSTRINGS");
        free(gstrings);
        close(sock);
        return 1;
    }

    // Step 3: 获取统计值
    size_t stats_len = sizeof(struct ethtool_stats) + n_stats * sizeof(__u64);
    struct ethtool_stats *stats = malloc(stats_len);
    if (!stats) {
        perror("malloc stats");
        free(gstrings);
        close(sock);
        return 1;
    }
    memset(stats, 0, stats_len);
    stats->cmd = ETHTOOL_GSTATS;
    ifr.ifr_data = (void *)stats;

    if (ioctl(sock, SIOCETHTOOL, &ifr) < 0) {
        perror("ETHTOOL_GSTATS");
        free(stats);
        free(gstrings);
        close(sock);
        return 1;
    }

    // Step 4: 输出统计信息
    printf("== Statistics for interface %s ==\n", ifname);
    for (int i = 0; i < n_stats; i++) {
        char name[ETH_GSTRING_LEN + 1] = {0};
        memcpy(name, gstrings->data + i * ETH_GSTRING_LEN, ETH_GSTRING_LEN);
        printf("%s: %llu\n", name, (unsigned long long)stats->data[i]);
    }

    free(gstrings);
    free(stats);
    close(sock);
    return 0;
}

```
