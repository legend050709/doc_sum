# 技术背景
## 1.1 什么是page fault?

缺页异常（page fault）也叫缺页中断，这其实不是真的程序“异常”或BUG， 而是一种故意的异常，可以认为是一个由硬件触发的可以由软件逻辑纠正的异常。

缺页异常是Linux内存管理很重要的一部分，很多Linux的特性都依赖其实现，例如写时复制（COW）, 内存延时分配，内存回收中的SWAP等。

还是觉得不够直观？ 举个例子，当应用程序使用malloc分配内存时，只是为其分配了虚拟内存，并没有为其分配真实的物理内存。当其使用内存时如memset时， 才会为其分配实际的物理内存， 这个过程就是通过缺页异常来实现的。

## 1.2 为什么需要page fault?

之所以需要page fault是因为内核引入的虚拟内存使得程序无法直接访问物理内存，那么访问虚拟内存时各种情况都需要进行处理， 这个处理的过程就需要page fault完成。

访问虚拟内存时会有以下这些情况：

1. 访问的地址不在虚拟地址空间中
2. 址址在虚拟地址空间，但其权限不够，如在R+X区域进行写，或R+W区域进行X
3. 地址还没有分配对应的物理内存，没有对应的映射
4. 地址对应的物理内存已经不在内存中
5. 映射的物理页权限不够
