# 执行方式
## bash or sh 执行
在执行 Shell 脚本的时候，通常都会创建一个新的 Shell ，比如，当我们执行：

```bash
bash script.sh
```

我们指明使用 `bash` 会创建一个新的 Shell 来执行 `script.sh` ，同时给定了这个执行环境默认的各种参数。

`set` 命令可以用来修改 Shell 环境的运行参数，不带任何参数的 `set` 命令，会显示所有的环境变量和 Shell 函数。
