# gcc编译开启代码中的宏定义
# 编译阶段

|阶段|输入文件|输出文件|作用|
|---|---|---|---|
|预处理|`.c`|`.i`|宏展开、文件包含展开|
|编译|`.i`|`.s`|生成汇编代码|
|汇编|`.s`|`.o`|生成机器码目标文件|
|链接|`.o` + 库文件|可执行文件|生成最终程序|

## 预处理（Preprocessing）
- 主要任务是处理以`#`开头的指令，如`#include`、`#define`、`#ifdef`等。
- 宏展开、文件包含、条件编译都会在这个阶段完成。
- 预处理的输出是纯文本的C代码，没有宏，所有`#include`都被展开了。


### 应用
C项目代码有很复杂的宏定义的逻辑，如何查看宏替换之后的代码。
```bash
gcc -E your_file.c -o your_file.i

有时候预处理文件里会有很多 `#` 开头的行号信息，如果不想看到它们：
gcc -E -P your_file.c -o your_file.i
```
