# 介绍
在很多日志 Log 函数的封装中，可以看到可变长参数函数。
C99中，出现了函数可变长参数特性，例如：printf 就可以接受任意长度的参数列表。看一下 `printf 「man 3 printf」` 函数的定义：
```c
#include <stdio.h>

int printf(const char *format, ...);
int fprintf(FILE *stream, const char *format, ...);
int sprintf(char *str, const char *format, ...);
int snprintf(char *str, size_t size, const char *format, ...);

#include <stdarg.h>

int vprintf(const char *format, va_list ap);
int vfprintf(FILE *stream, const char *format, va_list ap);
int vsprintf(char *str, const char *format, va_list ap);
int vsnprintf(char *str, size_t size, const char *format, va_list ap);
```
可以看到`printf`可变长参数除了有一个 format 固定参数外，其他参数的个数和类型就是可变的，用三个点 `...` 作为参数占位符，代表变长参数。
**固定参数**和**可选参数**共同构成变长参数函数的参数列表。

## 固定参数和可选参数
任何一个变长参数的函数都可以分为两部分：**固定参数**和**可选参数**。固定参数和可选参数共同构成变长参数函数的参数列表。

**固定参数**：至少要有一个固定参数，其声明与普通函数参数声明相同。
**可选参数**：可选参数由于数目不定（0个或以上），声明时用 `...` 表示。
**格式化字符串**：如上，`printf`的申明中，`format`就是格式化字符串。==格式化字符串是固定参数==。
**可变参数**：如上，`printf`的申明中，`...`就是可变参数。


## 变长参数函数的声明方式
可变参数函数的定义通常包含一个==固定参数列表，后面跟着一个省略号 `...`==。省略号表示可以有任意数量的附加参数。

```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
void func(char *p,...);
int main(int argc,char **argv)
{
    func("123",1,2,3,4,"",12.345);
    return 0;
}

//正确的
void func(char *p, ...)
{
    
}

//错误的
void func2(..., char *p)
{
    
}

//错误的
void func3(...)
{
    
}
```



```c
#include <stdarg.h>
#include <stdio.h>
// 定义一个可变参数函数
void __attribute__((format(printf,1,2))) my_printf(char *fmt,...)
{
    va_list args;
    va_start(args,fmt);
    vprintf(fmt,args);
    va_end(args);
}
int main() {
    my_printf("Hello, %s! Today is %s.\n", "world", "Monday");
    return 0;
}
```

# 可变参数函数的发展历程
## 变参函数v1.0版本
```c
void print_num(int count, ...)  
{  
    int *args;  
    args = &count + 1;  
    for( int i = 0; i < count; i++)  
    {  
        printf("*args: %d\n", *args);  
        args++;  
    }  
}  
int main(void)  
{  
    print_num(5,1,2,3,4,5);  
    return 0;  
}
```

变参函数的参数存储其实跟 main 函数的参数存储很像，由一个连续的参数列表组成，列表里存放的是每个参数的地址。
**在上面的函数中，有一个固定的参数 count，这个固定参数的存储地址后面，就是一系列参数的指针**。

在 print_num 函数中，先获取 count 参数地址，然后使用 &count + 1 就可以获取下一个参数的指针地址，使用指针变量 args 保存这个地址，并依次访问下一个地址，就可以直接打印传进来的各个实参值了。程序运行结果如下：
```c
*args：1  
*args：2  
*args：3  
*args：4  
*args：5
```


## 变参函数v2.0版本
上面的程序使用一个 `int *` 的指针变量依次去访问实参列表。我们接下来把程序改进一下，使用 `char *` 类型的指针来实现这个功能，使之兼容更多的参数类型。
```c
void print_num2(int count,...)  
{  
    char *args;  
    args = (char *)&count + 4;  
    for(int i = 0; i < count; i++)  
    {  
        printf("*args: %d\n", *(int *)args);  
        args += 4;  
    }  
}   
int main(void)  
{  
    print_num2(5,1,2,3,4,5);  
    return 0;  
}
```
在这个程序中，我们使用`char *` 类型的指针。
==涉及到指针运算，一定要注意每一个参数的地址都是4字节大小，所以我们获取下一个参数的地址是： `(char *)&count + 4;` ==。

不同类型的指针加1操作，转换为实际的数值运算是不一样的。对于一个指向 int 类型的指针变量`p`，`p+1`表示 `p + 1 * sizeof(int)` ，对于一个指向 `char` 类型的指针变量，`p + 1` 表示 `p + 1 * sizeof(char)` 。两种不同类型的指针，其运算细节就体现在这里。当然，程序最后的运行结果跟上面的程序是一样的，如下所示：
```c
*args：1  
*args：2  
*args：3  
*args：4  
*args：5
```


## 变参函数v3.0版本
对于变参函数，编译器或计算机系统一般会提供一些宏给程序员使用，用来解析函数的参数。这样程序员就不用自己解析参数了，直接使用封装好的宏即可。编译器提供的宏有：
```c
- va_list：定义在编译器头文件中 typedef char* va_list; 
- va_start(args,fmt)：根据参数 fmt 的地址，获取 fmt 后面参数的地址，并保存在 args 指针变量中。
- va_end(args)：释放 args 指针，将其赋值为 NULL。
- va_arg(va_list ap, type)：该宏返回下一个额外的参数，是一个类型为 type 的表达式。

```

有了这些宏，我们的工作就简化了很多。我们就不用撸起袖子，自己解析了。

```c
void print_num3(int count,...)  
{  
    va_list args;  
    va_start(args,count);  
    for(int i = 0; i < count; i++)  
    {  
        printf("*args: %d\n", va_arg(args, int));  
    }   
    va_end(args);  
}  
int main(void)  
{  
    print_num3(5,1,2,3,4,5);  
    return 0;  
}
```

## 变参函数v4.0版本
在 V3.0 版本中，我们使用编译器提供的三个宏，省去了解析参数的麻烦。但打印的时候，我们还必须自己实现。在 V4.0 版本中，我们继续改进，使用 vprintf 函数实现我们的打印功能。vprintf 函数有2个参数，一个是格式字符串指针，一个是变参列表。在下面的程序里，我们可以将，使用 va_start 解析后的变参列表，直接传递给 vprintf 函数，实现打印功能。

```c
void my_printf(char *fmt,...)  
{  
    va_list args;  
    va_start(args,fmt);  
    vprintf(fmt,args);  
    va_end(args);  
}   
int main(void)  
{  
    int num = 0;  
    my_printf("I am litao, I have %d car\n", num);  
    return 0;  
}
```
## 变参函数v5.0版本

上面的 `my_printf()` 函数，基本上实现了跟 `printf()` 函数相同的功能：支持变参，支持多种格式的数据打印。接下来，我们还需要对其添加 `format` 属性声明，让编译器在编译时，像检查 `printf` 一样，检查 `my_printf()` 函数的参数格式。 GNU 通过 `attribute` 扩展的 `format` 属性，用来指定变参函数的参数格式检查。 它的使用方法如下：
```c
__attribute__(( format (archetype, string-index, first-to-check)))  

比如：
void LOG(const char *fmt, ...) __attribute__((format(printf,1,2)));
```

属性 `format(printf,1,2)` 有三个参数。第一个参数 `printf` 是告诉编译器，按照 `printf` 函数的检查标准来检查；第2个参数表示在 `LOG` 函数所有的参数列表中，格式字符串的位置索引；第3个参数是告诉编译器要检查的参数的起始位置。

`V5.0` 版本如下：
```c
void __attribute__((format(printf,1,2))) my_printf(char *fmt,...)  
{  
    va_list args;  
    va_start(args,fmt);  
    vprintf(fmt,args);  
    va_end(args);  
}   
int main(void)  
{  
    int num = 0;  
    my_printf("I am litao, I have %d car\n", num);  
    return 0;  
}
```

## 数据结构
### `va_list`
`va_list` 的 `va` 是`variable-argument`(可变参数)；`list` 就是列表的意思。

```c
typedef char * va_list;

```


## 函数宏
```c
// 把 n 圆整 到 sizeof(int) 的倍数, 即 n 的类型大小向上按照4「sizeof(int)」的倍数取整
#define _INTSIZEOF(n)    ( (sizeof(n)+sizeof(int)-1) & ~(sizeof(int)-1) )


// 初始化 ap 指针，使其指向第一个可变参数。v 是变参列表的前一个参数
#define va_start(ap,v)    ( ap = (va_list)&v + _INTSIZEOF(v) )

// 该宏返回当前变参值,并使 ap 指向列表中的下个变参
#define va_arg(ap, type)    ( *(type *)((ap += _INTSIZEOF(type)) - _INTSIZEOF(type)) )

// /将指针 ap 置为无效，结束变参的获取
#define va_end(ap)    ( ap = (va_list)0 )
```
### `_INTSIZEOF(n)`
若`1≤sizeof(n)≤4`，则`_INTSIZEOF(n)＝4`；若`5≤sizeof(n)≤8`，则`_INTSIZEOF(n)=8`。


### `va_start(ap,v)`
分析该宏含义时，我们需要知道两个知识点。
1. **栈的生长方向是由高地址向低地址。**
2. **默认情况下，函数的参数是通过栈传递，并且从右往左。**

==在使用的时候，一般用`va_start(ap,v)`这个宏初始化 ap 指针。初始化的结果是 ap 指向第一个变参==。
其中`v`是变参列表左边的第一个参数。即最后一个固定参数。
`va_start`宏首先根据`(va_list)&v`得到参数 `v` 在栈中的内存地址，加上`_INTSIZEOF(v)`即v所占内存大小后，使`ap` 指向 `v` 的下一个参数，即可变参数列表的首地址。

比如：如下的变参函数`printf`，其栈空间大致如下：
```c
printf("hello world %d",num);
```
![](attachments/Pasted%20image%2020250612222932.png)


### `va_arg(ap, type)`
**作用**：
这个宏取得 `type` 类型的可变==参数值==。

**说明**：
首先`ap += _INTSIZEOF(type)`，即 `ap` 跳过当前可变参数而指向下个变参的地址；
然后`ap-_INTSIZEOF(type)`得到当前变参的内存地址，类型转换后解引用，最后返回当前变参值。
==最终，`ap` 指向的是下一个参数的地址，返回的是当前参数的值==。

### `va_end(ap)`

`va_end` 宏使 `ap` 不再指向有效的内存地址，将`ap`设置为`NULL`, 正如我们指针使用完之后执行`NULL`一样。


# 可变长函数的实现
## 实现原理
### 背景知识
![](attachments/Pasted%20image%2020250611224407.png)
```bash
变长函数：
如上所示：
format：格式化字符串
a, b: 可变参数的列表

压入栈时，按照从右边到左边的顺序压入栈中，栈的生长方向是从高地址到低地址。
```
(1) 函数的形参是放在栈空间的。参数是从右边到左边压入到栈中的。栈的生长方向是从高地址到低地址生长的。
(2) 存放内存地址是连续的。理论上只要知道固定参数的地址，就可以推出从左到右的其他可变参数的地址。

![](attachments/Pasted%20image%2020250617101832.png)

### 分析
#### 核心问题
可变参函数的内部逻辑大致如下：
```c
int va_args(const char* format,...)  
{  
    /* 获取可变参数列表第一个参数的地址**/  
    va_list p_args;  
    va_start(p_args, format);  
      
    int idx;  
    int val;  
      
    /** 核心：遍历可变参数列表*/  
    for(idx = 1; idx <= arg_cnt; ++idx){  
        val = va_arg(p_args, type);  
        printf("第 %d 个参数: %d\n", idx, val);  
    }  
    printf("---------------\n");  
  
    /** 释放*/  
    va_end(p_args);  
}
```
由上可知，利用`va_list`实现可变参数需要解决两个核心问题：
（1）如何确认变参的个数`arg_cnt`
（2）如何确认每个变参的类型

**解决思路**
变参宏无法智能识别可变参数的数目和类型，因此实现变参函数时需自行判断可变参数的数目和类型。
前者：可显式提供变参数目或设定遍历结束条件(如-1、'\0'或回车符等)。
后者：可显式提供变参类型枚举值，或在固定参数中包含足够的类型信息(如`printf`函数通过分析`format`格式化字符串即可确定各变参类型)，甚至主调函数和被调函数可约定变参的类型等。

#### 方式一：约定变参的数目和类型
比如：**函数通过固定参数指定可变参数个数，并约定参数列表类型**。

##### 范例1：约定个数+固定类型
范例如下：
```c
//2.c  
#include <stdarg.h>  
#include <stdio.h>  
  
/** arg_cnt表示可变参数列表的个数，并约定可变参数全部为int类型*/  
void parse_valist_by_num(int arg_cnt, ...);  
  
int main(void)  
{  
    parse_valist_by_num(4,1,2,3,4);  
}  
  
//第一个参数表示可变参数的个数  
void parse_valist_by_num(int arg_cnt, ...)  
{  
      
    va_list p_args;  
    va_start(p_args, arg_cnt);  
      
    int idx;  
    int val;  
      
    for(idx = 1; idx <= arg_cnt; ++idx){  
        val = va_arg(p_args, int);  
        printf("第 %d 个参数: %d\n", idx, val);  
    }  
    printf("---------------\n");  
    va_end(p_args);  
}
```

输出如下：
```bash

$ ./2  
第 1 个参数: 1  
第 2 个参数: 2  
第 3 个参数: 3  
第 4 个参数: 4  
---------------
```


##### 范例2：约定结束标记+固定类型
函数定义一个结束标记，调用时通过最后一个参数传递该标记，以结束变参的遍历打印。
```c
//最后一个参数作为变参结束符(-1)，用于循环获取变参内容
void ParseVarArgByEnd(int dwStart, ...){
    va_list pArgs = NULL;
    va_start(pArgs, dwStart);
    int dwArgIdx = 0;
    int dwArgVal = dwStart;
    while(dwArgVal != -1){
        ++dwArgIdx;
        printf("The %dth Argument: %d\n",dwArgIdx, dwArgVal);
        dwArgVal = va_arg(pArgs, int); //得到下个变参值
    }
    va_end(pArgs);
}
```

```bash
 调用方式为ParseVarArgByEnd(44, 55, -1);，输出：
 The 1th Argument: 44
 The 2th Argument: 55
```

##### 范例3：枚举类型 + 变参中传递参数类型和参数值
函数自定义一些可能出现的参数类型，在变参列表中显式指定变参类型。
可这样传递参数：参数个数,可变参数类型1,可变参数值1,可变参数类型2,可变参数值2,....。

```c
//可变参数采用<ArgType, ArgValue>的形式传递，以处理不同的变参类型
typedef enum{
    CHAR_TYPE = 1,
    INT_TYPE,
    LONG_TYPE,
    FLOAT_TYPE,
    DOUBLE_TYPE,
    STR_TYPE
}E_VAR_TYPE;
void ParseVarArgType(int dwArgNum, ...){
    va_list pArgs = NULL;
    va_start(pArgs, dwArgNum);

    int i = 0;
    for(i = 0; i < dwArgNum; i++){
        E_VAR_TYPE eArgType = va_arg(pArgs, int);
        switch(eArgType){
            case INT_TYPE:
                printf("The %dth Argument: %d\n", i+1, va_arg(pArgs, int));
                break;
            case STR_TYPE:
                printf("The %dth Argument: %s\n", i+1, va_arg(pArgs, char*));
                break;
            default:
                break;
        }
    }
    va_end(pArgs);
}
```

```c
调用方式为：
	ParseVarArgType(2, INT_TYPE, 222, STR_TYPE, "HelloWorld!");
输出：
 The 1th Argument: 222
 The 2th Argument: HelloWorld!
```



#### 方式二：`printf`或`vsprintf`的实现

**`printf`函数是如何解决这两个问题的呢？**
（1）变参个数。
通过固定参数`format`字符串中`%`的个数确定。

（2）每个变参的类型。
通过固定参数`format`字符串中`%`后的字符确定。比如：
`%c`,表示该参数是`char`类型， 则`va_arg(p_args, int)`;
`%f`,表示该参数是`float`类型，则`va_arg(p_args, double)`。

##### 范例1：chagpt给出的`vsprintf`的实现

**需求**：
```bash
不考虑宽度、精度、左对齐，零填充等，自定义实现一个准确的，相对比较完善的snprintf，包含vsnprintf函数。
```

**分析**：
我们不需要考虑复杂的格式化选项（如宽度、精度、左对齐等），只实现基本的格式化转换说明符。  
支持的格式化说明符包括：`%d, %i, %u, %o, %x, %X, %c, %s, %p, %%`  
长度修饰符：`hh, h, l, ll, z, j, t` 等（但因为我们简化了，所以可以适当处理整数提升）

设计思路：
```bash
1. 使用一个指针遍历格式字符串。
2. 当遇到'%'时，解析后面的格式说明符，否则直接复制字符。
3. 对于每个格式说明符，从va_list中取出相应参数，并转换为字符串。
4. 将转换后的字符串输出到缓冲区，注意缓冲区边界。

注意：需要返回应该写入的字符数（不包括结尾的'\0'），如果缓冲区空间不足，则复制尽可能多的字符，并在最后添加'\0'，
但返回的数值是不包括截断情况下应写入的总长度（类似于标准的snprintf）。

我们只实现以下转换：  
%d, %i: 有符号十进制整数  
%u: 无符号十进制整数  
%o: 无符号八进制整数  
%x, %X: 无符号十六进制整数（x小写，X大写）  
%c: 字符  
%s: 字符串  
%p: 指针（以十六进制输出，通常带0x前缀）  
%%: 输出'%'

对于有符号整数：  
hh: (int)va_arg(args, int) 然后转换为 signed char  
h: (short)va_arg(args, int)  
l: va_arg(args, long)  
ll: va_arg(args, long long)  
j: va_arg(args, intmax_t)  
z: va_arg(args, size_t) -> 转为intmax_t（注意：size_t可能比intmax_t大？但通常不会，这里简化）  
t: va_arg(args, ptrdiff_t)

无符号类似。
```

**代码实现**：
```c
#include <stdarg.h>
#include <stdbool.h>
#include <stdint.h>
#include <string.h>

// 辅助函数：无符号整数转字符串
static int uitoa(char *buf, uintmax_t num, int base, bool uppercase) {
    const char *digits = uppercase ? "0123456789ABCDEF" : "0123456789abcdef";
    int i = 0;
    
    // 处理0的特殊情况
    if (num == 0) {
        buf[i++] = '0';
    } else {
        // 从低位到高位转换
        while (num != 0) {
            uintmax_t rem = num % base;
            buf[i++] = digits[rem];
            num /= base;
        }
    }
    
    // 反转字符串（因为转换结果是倒序的）
    int start = 0, end = i - 1;
    while (start < end) {
        char temp = buf[start];
        buf[start] = buf[end];
        buf[end] = temp;
        start++;
        end--;
    }
    
    buf[i] = '\0'; // 添加终止符
    return i;      // 返回字符串长度
}

// 核心格式化函数
static int format_output(char *buf, size_t size, const char *format, va_list args) {
    size_t written = 0;  // 已写入缓冲区的字符数
    int total = 0;       // 总字符数（包括未写入的）

    while (*format) {
        // 缓冲区剩余空间检查
        size_t remaining = size > written ? size - written : 0;
        
        // 处理普通字符
        if (*format != '%') {
            if (written < size) buf[written] = *format;
            written++;
            total++;
            format++;
            continue;
        }
        
        // 跳过 '%'
        format++;
        if (*format == '\0') break;  // 格式字符串结束

        // 处理格式说明符
        switch (*format) {
            case '%': {  // 转义%
                if (remaining > 0) buf[written] = '%';
                written++;
                total++;
                break;
            }
            case 'c': {  // 字符
                char c = (char)va_arg(args, int);
                if (remaining > 0) buf[written] = c;
                written++;
                total++;
                break;
            }
            case 's': {  // 字符串
                const char *str = va_arg(args, const char*);
                if (!str) str = "(null)";
                
                while (*str) {
                    if (remaining > 0) buf[written] = *str;
                    if (remaining > 0) remaining--;
                    written++;
                    total++;
                    str++;
                }
                break;
            }
            case 'd':   // 有符号十进制整数
            case 'i': {
                int num = va_arg(args, int);
                char temp[32];
                int len;
                
                if (num < 0) {
                    // 处理负数
                    uintmax_t abs_num = (num == INT_MIN) ? (uintmax_t)INT_MAX + 1 : -num;
                    len = uitoa(temp, abs_num, 10, false);
                    
                    // 添加负号
                    if (remaining > 0) buf[written] = '-';
                    if (remaining > 0) remaining--;
                    written++;
                    total++;
                } else {
                    len = uitoa(temp, num, 10, false);
                }
                
                // 复制数字字符串
                for (int i = 0; i < len; i++) {
                    if (remaining > 0) buf[written] = temp[i];
                    if (remaining > 0) remaining--;
                    written++;
                    total++;
                }
                break;
            }
            case 'u': { // 无符号十进制整数
                unsigned int num = va_arg(args, unsigned int);
                char temp[32];
                int len = uitoa(temp, num, 10, false);
                
                for (int i = 0; i < len; i++) {
                    if (remaining > 0) buf[written] = temp[i];
                    if (remaining > 0) remaining--;
                    written++;
                    total++;
                }
                break;
            }
            case 'x':   // 十六进制整数（小写）
            case 'X': { // 十六进制整数（大写）
                unsigned int num = va_arg(args, unsigned int);
                char temp[32];
                int len = uitoa(temp, num, 16, (*format == 'X'));
                
                for (int i = 0; i < len; i++) {
                    if (remaining > 0) buf[written] = temp[i];
                    if (remaining > 0) remaining--;
                    written++;
                    total++;
                }
                break;
            }
            case 'o': { // 八进制整数
                unsigned int num = va_arg(args, unsigned int);
                char temp[32];
                int len = uitoa(temp, num, 8, false);
                
                for (int i = 0; i < len; i++) {
                    if (remaining > 0) buf[written] = temp[i];
                    if (remaining > 0) remaining--;
                    written++;
                    total++;
                }
                break;
            }
            case 'p': { // 指针地址
                void *ptr = va_arg(args, void*);
                uintptr_t ptr_val = (uintptr_t)ptr;
                
                // 添加 "0x" 前缀
                if (remaining > 0) buf[written] = '0';
                if (remaining > 0) buf[written + (remaining > 1 ? 1 : 0)] = 'x';
                written += 2;
                total += 2;
                if (remaining > 0) remaining = remaining > 2 ? remaining - 2 : 0;
                
                // 转换指针值
                char temp[20];
                int len = uitoa(temp, ptr_val, 16, false);
                
                // 输出十六进制值
                for (int i = 0; i < len; i++) {
                    if (remaining > 0) buf[written] = temp[i];
                    if (remaining > 0) remaining--;
                    written++;
                    total++;
                }
                break;
            }
            default: {  // 无效格式说明符
                // 原样输出%和无效字符
                if (remaining > 0) buf[written] = '%';
                written++;
                total++;
                
                if (*format) {
                    if (remaining > 0) buf[written] = *format;
                    written++;
                    total++;
                }
                break;
            }
        }
        format++;
    }
    
    // 添加终止null字符
    if (size > 0) {
        buf[written < size ? written : size - 1] = '\0';
    }
    
    return total;  // 返回总共应该写入的字符数
}

// vsnprintf实现
int my_vsnprintf(char *buf, size_t size, const char *format, va_list args) {
    if (!buf && size != 0) return -1;  // 安全检测
    return format_output(buf, size, format, args);
}

// snprintf实现
int my_snprintf(char *buf, size_t size, const char *format, ...) {
    va_list args;
    va_start(args, format);
    int ret = my_vsnprintf(buf, size, format, args);
    va_end(args);
    return ret;
}
```

static char print_buf[BUFFER_SIZE];  
static char num_to_char[] = "0123456789ABCDEF";  

/*
* 将10进制数据，按照N进制字符串形式保持
* num: 10进制的数据
* base：要转换的N进制

int fillD(char print_buf[],int k,int num,int base)  
{  
    int i;  
    int tmp;  
    char tmp_str[BUFFER_SIZE] = {0};  
    int tmp_index = 0;  
  
    if(num == 0)  
        tmp_str[tmp_index++] = '0';  
    else if(num < 0)        //如果是负数的话，记录下符号后转为相反的数  
    {  
        print_buf[k++] = '-';  
        num = -num;  
    }
    //将num转化为base进制的数据  
    while(num > 0)

        tmp_str[tmp_index++] = num_to_char[tmp];     //入栈，填入字符型数字  
  
        num = num / base;  
    }
    //将字符型数字出栈倒入buf中， 即逆序保持到 print_buf 中即可。
    for(i = tmp_index-1;i>=0;--i)  
    {  
        print_buf[k++] = tmp_str[i];  
    }
    return k;  
}

               }  
           }  
           else

#### 注意
**注意**:`va_arg(ap, type)`宏中的 `type` 不可指定为以下类型：

```bash
（1）char、signed char、unsigned char
（2）short、unsigned short、signed short、short int、signed short int、unsigned short int
（3）float
```

在C语言中，调用不带原型声明或声明为变参的函数时，**主调函数**会在传递未显式声明的参数前对其执行**缺省参数提升(default argument promotions)**，将提升后的参数值传递给**被调函数**。
提升操作如下：
- `float` 类型的参数提升为 `double` 类型
- `char`、`short` 和相应的 `signed`、`unsigned` 类型参数提升为 `int` 类型
- 若 `int` 类型不能容纳原值，则提升为 `unsigned int` 类型

在`gcc` 编译器中，若`type`使用`char`或`unsigned short int`等需提升的类型，可能会得到严重警告。 
因此，若要获取变参数列表中`float`类型的实参，则变参函数中应使用
`double dVar = va_arg(ap, double)`或`float fVar = (float)va_arg(ap, double)`。
`char`和`short`类型实参处理方式与之类似。

# 变长参数的传递
## 变长函数中变长参数的传递
C语言层面上无法将函数A的可变参数直接传递给函数B。只能定义被调函数的参数为va_list类型，在主调函数中将可变参数列表转换为va_list，再进行可变参数的传递。

如下所示，`snprintf`的实现：
```c
#include <stdarg.h>
#include <stdio.h>

int my_snprintf(char *str, size_t size, const char *format, ...) 
 
{
      //定义一个可变参数列表变量，用来保存"..."  
      va_list args;
 
      //可变参数列表初始化，其中args是可变参数列表变量，format为指定的格式，其作用是让args 指向可变参数列表中的第一个元素
      va_start(args, format); 
 
      //格式化字符串并复制到str
      int result = vsnprintf(str, size, format, args);
 
      //释放内存,配合va_start使用
      va_end(args);

      //返回实际写入字符串长度    
      return result;
}
```


`vsnprintf`函数原型为：
```c
int vsnprintf(char *str, size_t size, const char *format, va_list ap)。
```


## 变长参数宏中变长参数的传递
### 变长参数宏

变参宏的实现形式其实跟变参函数差不多：用 ... 表示变参列表，变参列表由不确定的参数组成，各个参数之间用逗号隔开。
可变参数宏使用 C99 标准新增加的一个 `__VA_ARGS__` 预定义标识符来表示前面的变参列表，而不是像变参函数一样，使用 va_list 、va_start 、 va_end 这些宏去解析变参列表。预处理器在将宏展开时，会用变参列表替换掉宏定义中的所有`__VA_ARGS__` 标识符。

### 问题
变长参数函数`printf`的声明为：`printf(const char *fmt, ...);`。
其中的`...` 就代表不固定的参数，使用起来十分方便。但是在函数嵌套的时候，不能直接使用`...` 来传递。
例如代码：
```c
#define logerr(s, ...) do { fprintf(stderr, s, ...); } while (0)
```
编译时就会报错：
```bash
va_args.c:4:50: error: expected expression before 「...」 token

#define logerr(s, ...) do { fprintf(stderr, "s", ...); } while (0)
```

### 解决
#### 方式一：`__VA_ARGS__`
如果要嵌套使用，需要通过宏`__VA_ARGS__`完成：
```c
#define logerr(s, ...) do { fprintf(stderr, s, __VA_ARGS__); } while (0)
```

#### 方式二：设定可变参数名称
函数宏中可变参数设置名称为：`xxx...`, 其中 `xxx`即可变参数的名称，后面的`...`，表示可变参数。

```c
#define LOG_INFO(fmt, args...) fprintf(stdout, "%d|"fmt"\n", __LINE__, ##args)
```
标识符中的`...`代表可变参数；
`args`表示可变参数的名字，用于可变长参数的传递；
`__LINE__`是编译器内置的宏定义，表示当前行号。

### 变长参数的个数为0的问题
```c
#define LOG(fmt, ...) printf(fmt, __VA_ARGS__)
```
在这个宏定义中，有一个固定参数，通常为一个格式字符串，后面的变参用来打印各种格式的数据，跟前面的格式字符串相匹配。
这种定义方式有一个漏洞，即当变参为空(变参个数为0)时，宏展开时就会产生一个语法错误。
```c
#define LOG(fmt,...) printf(fmt,__VA_ARGS__)  
int main(void)  
{  
    LOG("hello\n");  
    return 0;  
}
```
对于以上宏定义，如果我们传入的可变参数为空，会造成`printf`参数中多了一个逗号从而报错。
我们只给 LOG 宏传递了一个参数，而变参为空。当宏展开后，就变成了下面这个样子。
```c
printf("hello\n", );
```

### `##__VA_ARGS__`

#### 宏连接符`##`
宏连接符`##`的主要作用就是连接两个字符串，我们在宏定义中可以使用 `##` 来连接两个字符。预处理器在预处理阶段对宏展开时，会将`##` 两边的字符合并，并删除 `##` 这两个字符。
```c
#define CONNECT2(__A, __B)    __A##__B  
int safe_atom_code(void)  
{  
    uint32_t CONNECT2(wTemp,__LINE__) = __disable_irq();   
    /* do something here */  
    __set_PRIMASK(CONNECT2(wTemp,__LINE__));  
    return 0;  
}
```
假设`__LINE__`所在的行号为123，那么这里定义的变量名字就为`wTemp123`。

### `##__VA_ARGS__`的作用

为了解决这个问题，使用`##`表示如果可变参数为空，预处理器将去除掉它前面的那个逗号。
```c
#define debug(format, ...) fprintf(stderr, format, ##__VA_ARGS__)
```
这里变参列`...`没有名字， `__VA_ARGS__`就是可变参数宏，这里相当于把可变参数传到了`fprintf`里。
`##__VA_ARGS__`也是在没有可变参数时，去掉逗号。


### 可变参数宏调用其他的可变参数宏
```c
#include <stdio.h>

// 定义一个可变参数宏，用于打印格式化的参数
#define PRINT_FORMATTED(fmt, ...) \
    printf(fmt, ##__VA_ARGS__)

// 定义一个可变参数宏，用于打印带有前缀的参数
#define PRINT_WITH_PREFIX(prefix, ...) \
    do { \
        printf("%s: ", prefix); \
        PRINT_FORMATTED(__VA_ARGS__); \
        printf("\n"); \
    } while (0)

int main() {
    // 使用宏打印不同类型的参数
    PRINT_WITH_PREFIX("信息", "整数: %d, 浮点数: %.2f, 字符串: %s", 42, 3.14, "Hello, World!");
    PRINT_WITH_PREFIX("调试", "只打印一个整数: %d", 100);
    PRINT_WITH_PREFIX("警告", "没有参数");

    return 0;
}

```
说明：
如上所示：`PRINT_WITH_PREFIX` 中的 `...` 其实对应到 `PRINT_FORMATTED` 中的 `fmt, ...`;
如果只有`fmt`，没有后面的参数，由于 `PRINT_FORMATTED` 的展开中使用了 `##__VA_ARGS__` 可以去掉前面的逗号。



# 其他
## 变参列表中包含函数指针


(1)对于`VC6.0`，使用`va_arg`宏获取变参列表中类型为函数指针的参数时，可能需要将函数指针用`typedef`定义为新的数据类型，以便通过编译(与`va_arg`宏的实现有关)。

如：
```c
va_arg(argp, int(*)());
```

被扩展为以下形式(为缩减长度直接写出`_INTSIZEOF`宏值)
```c
( *(int (*)() *)((pArgs += 4) - 4) );

显然，(int (*)() *)无意义。
```


解决方法如下:
```c
typedef int (*pFunc)();

va_arg(argp, pFunc)被扩展为(*(pFunc *)((pArgs += 4) - 4))，即可通过编译检查。
```

(2) 在`gcc`编译器下，`va_arg`宏可直接使用函数指针类型。
```c
//for Gcc Compiler
int DummyFunc(void) { 
	printf("Here!!!\n");
	return 0;
}

void ParseFuncPtrVarArg(int i, ...){
    va_list pArgs = NULL;
    va_start(pArgs, i);
    char *sVal = va_arg(pArgs, char*);
    va_end(pArgs);
    printf("%d %s ", i, sVal);

    int (*pf)() = va_arg(pArgs, int (*)());
    pf();
}


以 ParseFuncPtrVarArg(1, "Welcome", DummyFunc);方式调用，
输出为: 1 Welcome Here!!!。
```

## 变长参数的访问
可变参数必须从头到尾按照顺序逐个访问。可访问几个变参后中止，但不能一开始就访问变参列表中间的参数。



## 固定参数中表明的变长参数和实际变长参数不匹配问题

调用变参函数时，传递的变参数目应不少于该函数所期望的变参数目(该数目由主调函数实参指定或由变参函数内部实现决定)，否则会访问到函数参数以外的堆栈区域，可能导致堆栈错误。

### 背景
我们在项目中经常会使用开源库进行日志打印，比如`easylog`。项目开发过程中，往往因为粗心，会写出如下的代码。
```c
log_i("debug info %s");  
log_d("num:%d str:%s",num,str,ptr);
```
**影响**
因为这些低级错误，往往出现一些异常现象，比如`crash`，并且很难排查。

### 分析
#### 范例一：个数不匹配
```c
log_i("debug info %s");
```
分析： 通过固定参数中可知，可变参数个数为1，但实际并没有传入实参。也就是说，`va_arg(ap,t)`得到的地址，是栈中的一个不确定地址。并将地址上的值，当作字符串输出。很显然，非常容易造成非法地址访问问题。

如下：
```c
//3.c  
#include<stdio.h>  
int main()  
{  
    printf("hello world %s\n");  
    return 0;  
}
```
编译&输出：

```bash
$ gcc 3.c -o 3 -Wformat=0  
$ ./3  
hello world t▒z  
```
我的运气不错，输出是乱码，并没有出现段错误。

#### 范例二：个数不匹配
```c
log_d("num:%d str:%s",num,str,ptr);
```
分析： 从固定参数中可知，可变参数个数为2，但实际传入实参有三个。也就是说最终并不会将第三个实参输出。但是对于函数的内部执行而言，似乎也并不会造成什么异常。

```c
//4.c  
#include<stdio.h>  
int main()  
{  
    int num = 1;  
    char * str = "hello world";  
    char * ptr = "C language";   
    printf("num:%d str:%s\n",num,str,ptr);  
    return 0;  
}
```
编译&输出：
```bash
$ gcc 4.c -o 4 -Wformat=0  
$ ./4  
num:1 str:hello world
```

### 解决
如何在工作中避免该类问题呢？
#### 方式一：`-Wformat -Wformat-security`编译参数
其实有一个**编译参数**可以帮助我们进行检测，那就是`-Wformat -Wformat-security`，它可以帮助我们进行固定参数和可变参数的个数和类型校验。

将问题在编译阶段暴露出来，避免在调试阶段出现异常，维护成本更高。

```bash
$ gcc 3.c -o 3  -Wformat -Wformat-security  
3.c: In function ‘main’:  
3.c:11:23: warning: format ‘%s’ expects a matching ‘char *’ argument [-Wformat=]  
   11 |  printf("hello world %s\n");  
      |                      ~^  
      |                       |  
      |                       char *  


$ gcc 4.c -o 4  -Wformat -Wformat-security  
4.c: In function ‘main’:  
4.c:15:12: warning: too many arguments for format [-Wformat-extra-args]  
   15 |     printf("num:%d str:%s\n",num,str,ptr);  
      |            ^~~~~~~~~~~~~~~~~  
```

#### 方式二：可变长参数函数在申明时添加类似于`__attribute__((format(printf, X, Y)))`属性
注：`__attribute__((format(printf, X, Y)))` 中的 `printf` 也可以是其他的函数名, 就会执行类似于 `printf` 的参数检查。
`y`和`x`分别指定可变长参数`...`的位置，以及左边最靠近变长参数`...`的固定参数的位置。

==该机制主要针对类似`scanf/printf`的变参函数，此类函数可根据格式化字符串(固定参数)确定变参数目和类型==。

# 小结
可变参数函数是C语言中常见的特性，允许函数接受数量不定的参数。 常见的实现方式是通过`va_list`系列函数，包括`va_start`、`va_arg`、`va_end`。
不正确使用可变参数，可能会导致程序崩溃（段错误）或其他安全问题。例如，如果调用函数时没有提供足够的参数，`va_arg`可能会访问非法的内存地址。

总结来说，要安全地使用可变参数函数，开发者应该：
5. **明确固定参数和可变参数的个数和类型。**
6. **使用编译器的警告选项（如-Wformat）来检测潜在的问题。**
7. **在函数调用时提供正确的参数数量和类型。**
8. **避免在可变参数列表后添加不必要的固定参数，这可能会导致安全漏洞。**
