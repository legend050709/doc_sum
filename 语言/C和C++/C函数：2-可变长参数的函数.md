# 函数宏
## 可变参数的函数宏
```c
#define LOG_INFO(fmt, args...) fprintf(stdout, "%d|"fmt"\n", __LINE__, ##args)
```
标识符中的`...`代表可变参数，`args`表示可变参数的名字；`__LINE__`是编译器内置的宏定义，表示当前行号。
对于以上宏定义，如果我们传入的可变参数为空，会造成`fprintf`参数中多了一个逗号从而报错。
为了解决这个问题，使用`##`表示如果可变参数为空，预处理器将去除掉它前面的那个逗号。

```c
#define debug(format, ...) fprintf(stderr, format, ##__VA_ARGS__)
```
这里变参列`...`没有名字， `__VA_ARGS__`就是可变参数宏，这里相当于把可变参数传到了`fprintf`里。
`##__VA_ARGS__`也是在没有可变参数时，去掉逗号。


### 可变参数宏调用其他的可变参数宏
```c
#include <stdio.h>

// 定义一个可变参数宏，用于打印格式化的参数
#define PRINT_FORMATTED(fmt, ...) \
    printf(fmt, ##__VA_ARGS__)

// 定义一个可变参数宏，用于打印带有前缀的参数
#define PRINT_WITH_PREFIX(prefix, ...) \
    do { \
        printf("%s: ", prefix); \
        PRINT_FORMATTED(__VA_ARGS__); \
        printf("\n"); \
    } while (0)

int main() {
    // 使用宏打印不同类型的参数
    PRINT_WITH_PREFIX("信息", "整数: %d, 浮点数: %.2f, 字符串: %s", 42, 3.14, "Hello, World!");
    PRINT_WITH_PREFIX("调试", "只打印一个整数: %d", 100);
    PRINT_WITH_PREFIX("警告", "没有参数");

    return 0;
}

```
说明：
如上所示：`PRINT_WITH_PREFIX` 中的 `...` 其实对应到 `PRINT_FORMATTED` 中的 `fmt, ...`;
如果只有`fmt`，没有后面的参数，由于 `PRINT_FORMATTED` 的展开中使用了 `##__VA_ARGS__` 可以去掉前面的逗号。
