# 标准IO流
## C++中的输入和输出

### C++中的输入和输出 和 C的输入输出对比

```C++
#include <iostream>
using namespace std;
int main()
{
	cout << "hello world!" << endl;
	return 0;
}

```
在C语言中有标准输入输出函数scanf和printf，而在C++中有**cin标准输入**和**cout标准输出**。在C语言中使用scanf和printf函数，需要包含头文件stdio.h。在C++中使用cin和cout，需要包含**头文件iostream**以及**std标准命名空间**。

C++的输入输出方式与C语言相比是更加方便的，因为**C++的输入输出不需要增加数据格式控制**，例如：整型为%d，字符型为%c。



## QA
###  `cin >> 变量` 和 `cout << 变量` 中的`<<` 和 `>>` 的方向到底代表什么？

在C++中，`cin >> 变量` 和 `cout << 变量` 里的 `>>` 和 `<<`，不要把它们理解成数学里的“大于小于号”，而要理解成“数据流动方向”。它们本质上是 **流运算符（stream operator）**，表示数据在 **流对象（stream）和变量之间的传输方向**。
> 注：可以这样理解：**记忆口诀：数据流向哪，尖就指向哪。**

#### `cout << 变量`：`变量 → 输出流 → 屏幕`

- **形象理解**：把 `<<` 看作一个**管道**，数据从右边的“变量”流向左边的 `cout`（控制台输出）。
- **尖头方向**：`<<` 的尖头**朝左**，表示数据**向左流动**，从程序流向输出设备。
- **读法**：“把变量插入到输出流中”。

```bash
（1）范例一：
int a = 10;
cout << a;

理解：
变量 a
  |
  |  数据流动
  ↓
cout 输出流
  |
  ↓
屏幕

（2）范例二：
cout << "Hello";  // 数据 "Hello" 从右边流向左边，被 cout 输出到屏幕

（3）范例三：
int a = 10;
int b = 20;

cout << a << b;

```

读作：把 `a` 插入（insert）到 `cout` 流中；
因此 `<<` 叫：插入运算符（insertion operator）


#### `cin >> 变量` —— 数据从键盘“流”进变量
- **形象理解**：把 `>>` 看作一个**管道**，数据从左边的 `cin`（键盘输入）流向右边的“变量”。
- **尖头方向**：`>>` 的尖头**朝右**，表示数据**向右流动**，从输入设备流向程序中的变量。
- **读法**：“从输入流中提取数据给变量”。

比如：`cin >> age`; // 键盘输入的数据从左边流向右边，存入 age 变量


```bash
int a;
cin >> a;

理解：
键盘
 |
 |
 ↓
cin 输入流
 |
 |
 ↓
变量 a
```

#### 为什么这样设计？—— 借用了“位移运算符”的符号

在C++中，`<<` 和 `>>` 原本是**位运算**（左移/右移），但被**重载（overload）**用于流操作。

- **`<<` 左移运算符**，二进制中是把位向左移，视觉上尖头朝左。
- **`>>` 右移运算符**，二进制中是把位向右移，视觉上尖头朝右。

C++保留了这种视觉方向感，让“尖头”天然指示了数据的**流动方向**。

##### `cin >> 变量` 和  `cout << 变量`其实是函数调用
`cout << a`; 其实等价于：`operator<<(cout, a)`;
也就是说：`cout << a` 调用了 operator<<(输出流, 数据)；

`cin >> a`; 其实等价于：`operator>>(cin, a)`;  调用了: `operator>>(输入流,变量)`

#### 链式使用（连续写）时的理解

比如：`cout << a << b << c`; 
因为：`cout << a` 返回的还是 cout对象；
```bash
(cout << a) << b

等价于

cout
 |
 +-- 输出a
 |
 +-- 输出b
 |
 +-- 输出c
```


#### 和 Linux 管道的类比

如果熟悉 Linux，可以把 C++ 的流理解成类似于 Shell 的管道。
例如：
```
cat file.txt | grep hello

数据流如下：
file
 │
 ▼
grep
 │
 ▼
输出
```

而 C++：
```
cout << data;

可以理解为：
data
 │
 ▼
cout
 │
 ▼
屏幕
```

二者都体现了“数据沿着流进行传递”的思想。

#### 小结

|代码|含义|数据方向|
|---|---|---|
|`cout << x`|输出 x|x → cout → 屏幕|
|`cin >> x`|输入到 x|键盘 → cin → x|
|`<<`|插入流|数据进入流|
|`>>`|提取流|数据离开流进入变量|


|写法|尖头方向|数据流向|实际作用|
|---|---|---|---|
|`cout << x`|朝左（<）|从右→左（x → cout）|**输出**到屏幕|
|`cin >> x`|朝右（>）|从左→右（cin → x）|**输入**到变量|
