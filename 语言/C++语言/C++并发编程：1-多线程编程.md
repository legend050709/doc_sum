# 线程库
在C++11之前，涉及到多线程 问题，都是和平台相关的，比如Windows和Linux下各有自己的接口，这使得代码的可移植性比较差。
C++11中最重要的特性就是对线程进行了支持，使得C++在并行编程时不需要依赖第三方库，而且在原子操作中还引入了原子类的概念。
