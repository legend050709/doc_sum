# 面向对象和面向过程
首先我们先给出以下结论：  
 **C语言是面向过程的，关注的是过程**，分析出求解问题的步骤，通过函数调用逐步解决问题。  
 **C++是基于面向对象的，关注的是对象**，将一件事拆分成不同的对象，靠对象之间的交互完成。

举例说明面向过程和面向对象的**区别**：
我们就**外卖系统**来看看面向过程和面向对象之间的区别：  
 面向过程，我们的关注点应该是**用户下单**、**骑手接单**以及**骑手送餐**这三个过程。  
 面向对象，那我们的关注点应该就是**客户**、**商家**以及**骑手**这三个类对象之间的关系。

## 类的成员函数（方法）

### 成员函数修饰
成员函数修饰写在**函数参数列表右括号后面**：`func() const;`、`func() &;`、`func() &&;`

#### const 成员函数：const写在函数后(对象相关的后缀修饰)
**专业叫法**：**常成员函数 (Const Member Function)**
- 注意：如果 `const` 放在返回值前面（如 `const int& func()`），那是修饰返回值的，这里我们只讨论放在参数列表后面的情况。


|特性|const 成员函数|非const 成员函数|
|---|---|---|
|能否被const对象调用| 可以| 不可以|
|能否修改成员变量| 不可以（mutable除外）| 可以|
|`this`指针类型|`const ClassName* const`|`ClassName* const`|
|可重载性|可与同名非const版本共存|只能有一个版本|



#### 左值（引用）限定成员函数 和 右值（引用）限定成员函数：（对象相关的后缀修饰）
`&`写在函数后：`&` 限定表示**只能被左值对象调用**；
`&&`写在函数后：`&&` 限定表示**只能被右值（临时）对象调用**。
```C++
class MyClass {
public:
    // 左值引用限定：只能被左值对象调用
    void func() & { 
        std::cout << "Called on lvalue object" << std::endl; 
    }
    
    // 右值引用限定：只能被右值对象调用
    void func() && { 
        std::cout << "Called on rvalue object" << std::endl; 
    }
};

int main() {
    MyClass obj;
    obj.func();           // ✅ 调用左值版本（obj 是左值）
    MyClass().func();     // ✅ 调用右值版本（临时对象是右值）
    std::move(obj).func(); // ✅ 调用右值版本
    return 0;
}
```

**不存在引用限定时**：
- 同一个函数名可以同时被左值和右值对象调用（没有重载区分）。    
- 编译器不会因为对象的左右值属性选择不同版本的函数。

**存在 vs 不存在的区别**：
|特性|有引用限定符|无引用限定符|
|---|---|---|
|重载可能性|可以区分左值和右值对象调用|只能有一个版本|
|安全性|可以对右值对象做移动语义优化|无法区分对象生命周期|
|常见用途|`vector::push_back(const T&)` 和 `push_back(T&&)` 的类外版本|大多数普通成员函数|

#### static 成员函数：static写在函数前
 **专业叫法**：**静态成员函数 (Static Member Function)**
 
**普通成员函数隐式包含一个 `this` 指针，代表调用它的对象；而静态成员函数没有 `this` 指针，它属于类本身，不属于任何对象。因此，static 成员函数不能访问普通的成员变量（因为没有this指针），只能访问静态成员，也不能用任何对象相关的后缀修饰（const、&、&& 全部报错「const、&、&& 是对象的后缀修饰」）**。

```C++
class Calculator {
private:
    static int count;  // 静态成员变量（所有对象共享）
    int id;            // 非静态成员变量（每个对象独立）
    
public:
    Calculator(int i = 0) : id(i) { count++; }
    ~Calculator() { count--; }
    
    // ===== 无 static =====
    // 属于对象，有this指针
    void printId() const {
        cout << "ID: " << id << endl;  // ✅ 可以访问非静态成员
        cout << "Count: " << count << endl;  // ✅ 可以访问静态成员
    }
    
    // ===== 有 static =====
    // 属于类，没有this指针
    static void printCount() {
        // cout << "ID: " << id << endl; // ❌ 错误：不能访问非静态成员
        cout << "Total count: " << count << endl;  // ✅ 只能访问静态成员
    }
};

int Calculator::count = 0;  // 静态成员必须在类外定义

int main() {
    Calculator c1(1), c2(2);
    
    // 无 static（必须通过对象调用）
    c1.printId();    // ✅ 可以
    // Calculator::printId(); // ❌ 错误：不能通过类名调用
    
    // 有 static（可通过类名或对象调用）
    Calculator::printCount(); // ✅ 推荐方式
    c1.printCount();          // ✅ 也可以，但不推荐
    return 0;
}
```


|特性|有 `static`|无 `static`|
|---|---|---|
|是否属于类本身|✅ 属于类，不属于对象|❌ 属于每个对象|
|能否通过对象调用|✅ 可以（`obj.func()`）|✅ 可以|
|能否通过类名调用|✅ 可以（`ClassName::func()`）|❌ 不可以|
|能否访问非静态成员|❌ 不可以（没有 `this` 指针）|✅ 可以|
|能否访问静态成员|✅ 可以|✅ 可以|
|有无 `this` 指针|❌ 没有|✅ 有|
|是否可被 `const`/引用限定|❌ 不可以（`static const` 成员函数不存在）|✅ 可以|

#### `virtual` 修饰成员函数
**专业术语**：virtual function（虚函数）

```C++
#include <iostream>
using namespace std;

class Animal {
public:
    // ===== 无 virtual =====
    // 静态绑定（编译时决定）
    void speak_non_virtual() const {
        cout << "Animal sound (non-virtual)" << endl;
    }
    
    // ===== 有 virtual =====
    // 动态绑定（运行时决定）
    virtual void speak_virtual() const {
        cout << "Animal sound (virtual)" << endl;
    }
    
    virtual ~Animal() {}  // 虚析构函数
};

class Dog : public Animal {
public:
    // 隐藏基类的非虚函数（不是重写）
    void speak_non_virtual() const {
        cout << "Dog bark (non-virtual)" << endl;
    }
    
    // 重写基类的虚函数（override）
    void speak_virtual() const override {
        cout << "Dog bark (virtual)" << endl;
    }
};

int main() {
    Dog dog;
    Animal* ptr = &dog;  // 基类指针指向派生类对象
    
    // 无 virtual：调用取决于指针类型（编译时绑定）
    ptr->speak_non_virtual();  // 输出: Animal sound (non-virtual)
    dog.speak_non_virtual();   // 输出: Dog bark (non-virtual)
    
    // 有 virtual：调用取决于对象类型（运行时绑定）
    ptr->speak_virtual();      // 输出: Dog bark (virtual)
    dog.speak_virtual();       // 输出: Dog bark (virtual)
    return 0;
}
```



##### 虚函数限定符（virtual specifiers）：`final` 和 `override`

**专业术语**：override specifier（覆盖限定符）、final specifier（最终限定符）;
(1) 修饰函数时：override 和 final 只能和虚函数相关。
(2) final修饰类的时候，表示该类不可以被继承。

|特性|有 `override`|无 `override`|
|---|---|---|
|编译器检查|✅ 确保重写基类虚函数|❌ 不检查（可能隐藏基类函数）|
|可读性|✅ 明确表示重写意图|❌ 不明确|
|容错性|编译失败及早发现错误|可能写错而不报错|

|特性|有 `final`|无 `final`|
|---|---|---|
|类能否被继承|❌ 不可以|✅ 可以|
|虚函数能否被重写|❌ 不可以|✅ 可以|

```C++
class Base {
public:
    virtual void func1() { cout << "Base::func1" << endl; }
    virtual void func2() { cout << "Base::func2" << endl; }
    virtual void func3() { cout << "Base::func3" << endl; }
};

class Derived : public Base {
public:
    // ===== 无 override =====
    // 容易写错而不自知
    void func1() {  // 少了virtual？仍然有效，但容易犯错
        cout << "Derived::func1" << endl;
    }
    
    // ===== 有 override =====
    // 明确表示重写，编译器检查
    void func2() override {  // ✅ 正确重写
        cout << "Derived::func2" << endl;
    }
    
    // void func3(int x) override { } // ❌ 错误：签名不匹配，编译失败
};

class FinalClass final {  // final修饰类，不能被继承
    // 这个类不能有派生类
};

class Base2 {
public:
    virtual void final_func() final {  // final修饰函数，不能被重写
        cout << "Base2::final_func (final)" << endl;
    }
};

class Derived2 : public Base2 {
public:
    // void final_func() override { } // ❌ 错误：final函数不能被重写
};
```

#### `explicit` 修饰成员函数
**专业术语**：`explicit` specifier（显式限定符）

C++ 构造函数默认支持**隐式类型转换**。在 C++ 中，如果一个类拥有一个**单参数构造函数**（或者除了第一个参数外其余参数都有默认值的多参数构造函数）， 编译器会自动做隐式转换：用入参类型的值悄悄构造出临时对象。这意味着编译器会在后台悄悄地将参数类型转换为该类的类型。很多时候这种自动转换毫无意义，会造成意料之外的 bug、代码可读性差。

C++ 引入 `explicit`，专门用来**禁止单参构造函数的隐式转换**，只允许显式调用构造。

##### 隐式转换发送的场景

三种场景：
（1）`类 对象=参数类型的值`
（2）函数参数自动转换；
（3）函数返回值自动转换；

```C++
#include <iostream>
using namespace std;

class String {
private:
    const char* data;
public:
    // 非explicit构造函数：允许隐式转换
    String(const char* str) : data(str) {
        cout << "String constructed from: " << str << endl;
    }
    
    void print() const {
        cout << data << endl;
    }
};

void takeString(const String& s) {
    s.print();
}

int main() {
    // ===== 隐式转换发生的地方 =====
    
    // 情况1：直接赋值
    String s1 = "Hello";  // ✅ 隐式转换：const char* -> String
    
    // 情况2：函数传参
    takeString("World");  // ✅ 隐式转换：const char* -> String
    
    // 情况3：返回值
    String getString() {
        return "Temp";    // ✅ 隐式转换：const char* -> String
    }
    
    return 0;
}
```

##### `explicit` 核心作用

（1）禁止单参数构造函数的**隐式转换**；
（2）禁止拷贝初始化语法 `类名 对象 = 参数类型的值`；
（3）只保留显式写法：`类名 对象(值)` / `类名 对象{值}`；
（4）杜绝函数传参、返回值时偷偷自动构造对象。

```C++
#include <iostream>
using namespace std;

class SafeString {
private:
    const char* data;
public:
    // explicit构造函数：禁止隐式转换
    explicit SafeString(const char* str) : data(str) {
        cout << "SafeString constructed from: " << str << endl;
    }
    
    void print() const {
        cout << data << endl;
    }
};

void takeSafeString(const SafeString& s) {
    s.print();
}

int main() {
    // ===== 隐式转换被禁止 =====
    
    // SafeString s1 = "Hello";  // ❌ 编译错误：不能从const char*隐式转换
    
    // 必须显式构造
    SafeString s2("Hello");      // ✅ 直接初始化（可以）
    SafeString s3 = SafeString("World");  // ✅ 拷贝初始化（显式）
    // takeSafeString("World");  // ❌ 编译错误：不能隐式转换
    
    takeSafeString(SafeString("World"));  // ✅ 必须显式构造
    
    // 或者使用static_cast
    takeSafeString(static_cast<SafeString>("World"));  // ✅ 
    
    return 0;
}
```

#### 范例：`[]`运算符的重载
```C++
namespace cl
{
	//模拟实现string类
	class string
	{
	public:
		//[]运算符重载（可读可写）
		char& operator[](size_t i)
		{
			assert(i < _size); //检测下标的合法性
			return _str[i]; //返回对应字符
		}
		//...
	private:
		char* _str;       //存储字符串
		size_t _size;     //记录字符串当前的有效长度
		//...
	};
}
int main()
{
	cl::string s("hello");
	s[3] = 'x';    //引用返回，支持外部修改
	return 0;
}

```

**理解**：
调用时：`[]`的左边是重载函数对应的类的实例对象，`[]`中的元素是参数。
整体：`xx[yy]：就是xx对象调用`[]`运算符重载函数的返回值，其中yy是函数参数`。比如此范例的`s[3]`

#### 范例：类型转换运算符(比如：`int()` )

```C++
#include <iostream>
#include <string>
using namespace std;

class Integer {
private:
    int value;
    
public:
    Integer(int v = 0) : value(v) {}
    
    // ===== 类型转换运算符重载 =====
    // 语法：operator 目标类型() const { return ...; }
    
    // 1. 转换为 int
    operator int() const {
        cout << "Converting Integer to int: " << value << endl;
        return value;
    }
    
    // 2. 转换为 double
    operator double() const {
        cout << "Converting Integer to double: " << value << endl;
        return static_cast<double>(value);
    }
    
    // 3. 转换为 bool（常见用途）
    operator bool() const {
        cout << "Converting Integer to bool: " << (value != 0) << endl;
        return value != 0;
    }
    
    // 4. 转换为 string（C++风格）
    operator std::string() const {
        cout << "Converting Integer to string: " << value << endl;
        return std::to_string(value);
    }
    
    // 获取值（方便调试）
    int get() const { return value; }
};

int main() {
    Integer num(42);
    
    // ===== 隐式转换发生的地方 =====
    
    // 1. 赋值转换
    int i = num;              // 调用 operator int()
    cout << "int: " << i << endl;
    
    // 2. 算术运算
    double d = num + 3.14;    // 调用 operator double()
    cout << "double: " << d << endl;
    
    // 3. 条件判断
    if (num) {                // 调用 operator bool()
        cout << "num is true" << endl;
    }
    
    // 4. 字符串拼接
    string s = "Value: " + static_cast<string>(num);  // 调用 operator string()
    cout << s << endl;
    
    // 5. 函数参数
    void printInt(int x) { cout << "printInt: " << x << endl; }
    void printBool(bool b) { cout << "printBool: " << (b ? "true" : "false") << endl; }
    
    printInt(num);            // 隐式转换为 int
    printBool(num);           // 隐式转换为 bool
    
    return 0;
}
```

#### 范例：`()`运算符的重载
```C++
class Add
{
public:
	Add(int base)
		:_base(base)
	{}
	int operator()(int num)
	{
		return _base + num;
	}
private:
	int _base;
};
int main()
{
	int base = 1;

	//函数对象
	Add add1(base);
	add1(1000);

	//lambda表达式
	auto add2 = [base](int num)->int
	{
		return base + num;
	};
	add2(1000);
	return 0;
}

```

**理解**：
调用时：`()`的左边是重载函数对应的类的实例对象，`()`中的元素是参数。
整体：`xx(yy)：就是xx对象调用`()`运算符重载函数的返回值，其中yy是函数参数`。比如此范例的`add1(1000)`;
